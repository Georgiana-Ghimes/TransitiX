CHANGELOG

Harta zonelor (/zone-map)

  • Pagină nouă Harta zonelor — în companion (documents) și pe TMS full.
  • Desenează pe OpenStreetMap contururile din tax_zones.polygon (ce citește calculul TPO).
  • Import contur din GeoJSON sau KML (WGS84) → salvare pe zonă.
  • Trasare pe hartă (click → noduri → Salvează conturul / Anulează / Undo).
  • Arată / ascunde zone; culori distincte pentru zone care se suprapun.
  • Referință perimetrală București Zona A / Zona B (liste de arterii PMB) — ghid la trasare, nu intră în calcul.

Verificare adresă pe zonă (= TPO)

  • Căutare adresă + MMA opțional → punct pe hartă, zona găsită, tarif aplicabil.
  • API POST /api/commercial/zones/locate: geocode pe calea comună, apoi resolveZone + findZoneRate (aceleași ca la TPO).
  • Răspuns: matched_by = polygon sau text (matcher pe text adresă).
  • Geocode din cache: city/county/postcode din candidat + parse adresă — ca zona să nu „dispară” la a doua căutare pe aceeași stradă.
  • Client: api.commercial.locateZone({ address, mmaKg, date }).

Librării + teste

  • src/lib/zoneGeometry.js — GeoJSON ↔ Leaflet (lon/lat), import, validări outline (toFiniteNumber, nu Number(null)).
  • src/lib/bucharestZones.js — referință ZA / ZB (perimetru stradal oficial).
  • Teste unitare: zoneGeometry.test.js, bucharestZones.test.js.
  • Teste API: zoneLocate.api.test.js (punct înăuntru / afară, fără geocode live).
