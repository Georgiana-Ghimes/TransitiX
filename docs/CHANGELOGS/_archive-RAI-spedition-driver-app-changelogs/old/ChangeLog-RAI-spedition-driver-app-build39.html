CHANGELOG

Autoturisme (/fleet)

  • Pagină nouă în companion și pe TMS full: listă plăcuțe, căutare, adăugare manuală.
  • Editare MTMA (kg) pe rând; salvare = confirmare (scoate marcajul OCR).
  • Vehicule deschise de OCR: badge „din OCR” — o plăcuță greșită citită nu se prezintă ca flotă introdusă de birou.
  • Alertă verificare date: vehicle_no_mma (error) → link la Autoturisme.

OCR → flotă + Harta zonelor

  • La extracție, plăcuța primară (tractoare, nu remorca din „B-… / B-…”) deschide vehicles cu added_by_ocr.
  • Formă unică de plăcuță: B-112-VFM (canonicalPlate) — OCR + backfill DB (vehicles + avize).
  • brand / model nu mai sunt obligatorii (înregistrare doar din plăcuță).
  • Harta zonelor: câmp Nr. auto; dacă MTMA e gol, se ia din flotă (mmaForPlate). Cifră tastată pe hartă rămâne prioritară.
  • Placeholder MMA → MTMA (kg).

Anexa Factura RAI — headere din cod

  • Șablonul locked nu mai citește coloanele vechi din DB (seed neschimbat) — exportul folosește mereu DEFAULT_RAI_COLUMNS.
  • Headere aliniate la foaia clientului: Nr. Crt., Cantitate marfa (tone), Taxe suplimentare, Tarif Km, etc.

BUGFIX

  • Greutate brută Baumit: etichetă cu unitatea înainte de cifră (Greutate bruta, kg 15,744.00) — înainte rămânea goală și anexa cădea pe numărul de găleți.
  • Ruta pe listă vs export: decorateAviz aplică repairAvizFromStored ca la export — tabela nu mai arată rută goală când XLSX-ul o are.

Testare rapidă

  1. Migrare / restart API → coloană added_by_ocr, plăcuțe normalizate.
  2. Companion → Autoturisme: adaugă plăcuță + MTMA; filtrează.
  3. Extrage un aviz cu nr. auto nou → apare în listă cu badge OCR; completează MTMA.
  4. Harta zonelor: doar nr. auto (fără MTMA) → tarif din flotă; sau MTMA tastat câștigă.
  5. Export Anexa RAI: headere tone / Taxe suplimentare; greutate Baumit pe tone.
  6. Avize: document cu rută doar în OCR text → coloana Ruta e umplută pe listă.
  7. Login / topbar: v1.5.0 - build 39 (după restart Vite).
Atenție: backfill-ul de plăcuțe rulează din baseline migrate.js (UPDATE idempotent). Pe DB-uri deja migrate, pornește din nou migrarea / rulează UPDATE-urile dacă plăcuțele vechi încă apar spațiate.
