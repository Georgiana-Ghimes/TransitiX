Build 34 · v1.4.0

Changelog

Harta zonelor (/zone-map)

  • Pagină nouă — în companion (documents) și pe TMS full.
  • Desenează pe OpenStreetMap contururile din tax_zones.polygon (ce citește calculul TPO).
  • Import contur din GeoJSON sau KML (WGS84) → salvare pe zonă.
  • Trasare pe hartă (click → noduri → Salvează / Anulează / Undo).
  • Arată / ascunde zone; culori distincte pentru zone care se suprapun.
  • Referință perimetrală București Zona A / Zona B (liste arterii PMB) — ghid la trasare, nu intră în calcul.

Verificare adresă pe zonă (= TPO)

  • Căutare adresă + MMA opțional → punct pe hartă, zona găsită, tarif aplicabil.
  • API POST /api/commercial/zones/locate: aceleași resolveZone + findZoneRate ca la TPO.
  • Răspuns: matched_by = polygon sau text.
  • Geocode din cache: city/county/postcode din candidat + parse — zona nu „dispare” la a doua căutare.
  • Client: api.commercial.locateZone({ address, mmaKg, date }).

Librării + teste

  • zoneGeometry.js, bucharestZones.js + teste unitare / API locate.

Build 37 · v1.4.3

Changelog

Index de străzi pe hartă (București)

  • Căutarea încearcă întâi indexul din browser (streetZones/) — la prima căutare, nu cu pagina.
  • Potrivire exactă, fără tip de stradă, ambiguă (alegi din listă), necunoscută → rezervă geocoder.
  • Stradă pe granița de zonă: indexul spune asta (nr. decide), nu ghicește un pin pe o parte.
  • Script regenerare: node scripts/build-street-zones.js. Normalizare: streetName.js.

Locate + UX pe Harta zonelor

  • Parametru city — strada goală din tab primește orașul.
  • Pin: arată și conturul desenat care conține punctul — separat de zona de preț din server.
  • Hint MMA: valori tipice în tone (< 100) → „pare în tone — pune … kg?”.
  • Placeholder: doar strada; orașul e tab-ul activ.

Geocoder: outage ≠ adresă greșită

  • Eșec de infrastructură nu se mai scrie în geocode_cache ca „negăsit”.
  • Doar 4xx se cache-uiește ca eroare de adresă.
  • POST /zones/locate → 503 + mesaj despre PHOTON_URL când geocoderul lipsește.
Bugfix
  • Adrese fără Photon configurat nu mai rămân blocate „negăsit” în cache.
  • Căutare stradă goală pe tab București nu mai pune pinul pe un omonim din țară.

Build 45 · v1.6.0 (curent)

Changelog

Ghid în aplicație (birou)

  • Meniu lateral: Ghid → /ghid (manual cu căutare, secțiuni pliante).
  • Turul ghidat nu mai pornește din sidebar; se reia din Ghid.

Ghid șofer

  • Companion: tab Ghid în bara de jos (Încărcă / Ghid / Profil).
  • App șofer full: buton ajutor în header.

Taxă zonă București în Editează aviz

  • Panou: taxă din adresa de livrare (index local), MTMA din Autoturisme și greutatea brută.
  • Completează Taxe suplimentare doar dacă e gol / 0; altfel „Pune / Înlocuiește”.
  • Mesaje când lipsește greutate, adresă, mașină sau MTMA; link spre Autoturisme.

OCR pe adresa de livrare

  • Păstrează tipul străzii (Șosea / Stradă / …), numele și numărul — deosebește omonime (ex. Viilor).

„Aviz duplicat” în loc de „TPO duplicat”

  • Același transport (același număr aviz PSL/TRO sub același TPO), nu orice TPO repetat.
  • Un TPO cu mai multe curse rămâne rânduri separate, fără etichetă falsă.

Titlu companion + texte mici

  • Titlu: RAI Spedition · Documente. MTMA lipsă: „necompletat”; fără plăcuță: „fără auto”.
Bugfix

False „TPO duplicat” pe curse legitime

  • Același TPO cu avize diferite nu mai e marcat duplicat la salvare, confirmare, export, clopot / verificări.
  • Duplicatul real = același număr de aviz încărcat de două ori (fără număr: zi + auto + rută).

Potrivire tip stradă „șosea”

  • Sinonimul e recunoscut și la rezolvarea adresei (zone / geocode), nu doar la OCR.
