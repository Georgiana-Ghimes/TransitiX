CHANGELOG

Zonă după numărul stradal (index București)

  • Indexul include STREET_NUMBERS: intervale impar/par pe străzile unde granița taie strada.
  • lookupAddress — încearcă numele întreg ca stradă; doar dacă nu există, desparte numărul final (splitStreetAndNumber). Astfel „Bd. 1 Decembrie 1918” nu pierde anul din nume.
  • zoneForNumber / resolveAddress — răspuns după număr; dacă numărul cade între două intervale cu zone diferite, ecranul spune intervalul, nu ghicește.
  • Stradă aflată integral într-o zonă: numărul nu e obligatoriu (fără „busywork”).
  • Script: node scripts/build-street-zones.js trage și adrese OSM (--no-addresses = doar străzi).

Harta zonelor — UX pe adresă

  • Placeholder: „Strada și numărul, ex. Calea 13 Septembrie 102”.
  • Rezultat: afișează numărul; „după numărul stradal” când e decisiv.
  • Avertismente clare: lipsește numărul pe stradă de graniță / număr necunoscut în index / între două zone — fără sumă inventată la Calcul.

Avize — legendă care rămâne pliată

  • Legendă acțiuni: dacă o închizi, rămâne închisă la refresh (collapsePreference în localStorage).
  • Fereastră privată / storage blocat: preferința se ignoră, ecranul nu crapă.

BUGFIX

  • Sugestia fuzzy nu mai „înghite” numărul din query (ex. „Bd. Dacia 5” → Dacia fără 5).

Testare rapidă

  1. Companion → Harta zonelor → București.
  2. Stradă integral în zonă (fără nr.) → zonă certă.
  3. Stradă de graniță fără nr. → avertisment „adaugă numărul”.
  4. Aceeași stradă cu nr. din index → zonă „după numărul stradal”.
  5. Avize → închide legenda acțiuni → refresh → rămâne închisă.
  6. Login / topbar: v1.4.4 - build 38 (după restart Vite).
