CHANGELOG

Index de străzi pe hartă (București)

  • Căutarea încearcă întâi indexul din browser (src/lib/streetZones/) — încărcat la prima căutare, nu cu pagina.
  • Răspunsuri: potrivire exactă, fără tip de stradă, ambiguă (alegi din listă), necunoscută → rezervă geocoder.
  • Stradă care traversează granița de zonă: indexul spune asta (nr. decide), nu ghicește un pin pe o parte.
  • Script regenerare: node scripts/build-street-zones.js (Overpass → bucuresti.js).
  • Normalizare nume: streetName.js (diacritice, tip stradă).

Locate + UX pe Harta zonelor

  • API / client: parametru city — strada goală din tab primește orașul (fără dublare dacă e deja în text).
  • Pin pe hartă: arată și conturul desenat care conține punctul (pointInGeometry) — separat de zona de preț din server.
  • Hint MMA: valori tipice în tone (< 100) → „pare în tone — pune … kg?” (nu se aplică singur).
  • Placeholder: doar strada; orașul e tab-ul activ.

Geocoder: outage ≠ adresă greșită

  • Eșec de infrastructură (neconfigurat / down) nu se mai scrie în geocode_cache — altfel rămânea „negăsit” după ce pui PHOTON_URL.
  • Doar 4xx (provider a refuzat cererea) se cache-uiește ca eroare de adresă.
  • POST /zones/locate → 503 + mesaj despre PHOTON_URL când geocoderul lipsește; UI: notă, nu „adresă greșită”.

BUGFIX

  • Adrese încercate fără Photon configurat nu mai rămân blocate „negăsit” în cache.
  • Căutare stradă goală pe tab București nu mai poate pune pinul pe un omonim din țară.

Testare rapidă

  1. Companion → Harta zonelor → tab București.
  2. Caută o stradă cunoscută (ex. Calea Victoriei) fără Photon — răspuns din index.
  3. Caută un nume ambiguu (ex. Dacia) — alege din sugestii.
  4. Stradă necunoscută + Photon lipsă → mesaj 503 / rezervă, nu „typo”.
  5. Cu Photon: strada + city din tab → pin corect; MMA 7,5 → hint tone.
  6. Login / topbar: v1.4.3 - build 37 (după restart Vite).
