CHANGELOG

Harta zonelor — MTMA din Autoturisme, mesaje clare

  • La încărcare, harta ia și flota; resolveVehicleMma rezolvă plăcuța local (inclusiv pe calea indexului de străzi, fără round-trip per căutare).
  • Cinci stări: fără număr / invalid / necunoscut / fără MTMA / găsit.
  • Mesaje cu link: Adaugă mașina sau Completează în Autoturisme → /fleet (aceleași pe index stradal și pe locate).
  • Cifră tastată pe hartă rămâne prioritară față de flota; dacă vine din flotă, se arată și plăcuța lângă tarif.

API locate — mașină cunoscută vs incompletă

  • vehicleForPlate: id + known + mmaKg (nu doar greutatea sau tăcere).
  • Răspuns: vehicle: { plate, known, has_mma } în loc de mma_from_plate.
  • Teste: unknown plate / fără plate / text care nu e plăcuță.

Autoturisme — MTMA blocat după salvare

  • Fără MTMA: câmpul rămâne deschis (motivul ecranului).
  • Cu MTMA: afișare read-only; creion → editare; Escape / X renunță; Enter salvează dacă e modificat.
