  • resetOcrCapabilityCache() pentru probe-ul cached între teste.

Build 61 · v1.8.2 · Re-extrage OCR în fundal (fără spinner infinit)

Changelog

  • Re-extrage pe aviz existent → 202 + OCR în fundal (buget lung), nu mai ține request-ul sub spinner.
  • Dacă Paddle e down: 503 imediat; buton Re-extrage dezactivat + probe health la 15s.
  • Client: abort la 130s; rândurile blocate pe uploaded se curăță după updated_at (nu created_at).

Bugfix

  • Pe poze grele: OCR_TIMEOUT la 120s; tunelul tăia răspunsul înainte de retry → UI rămânea pe „Se re-extrage…” la nesfârșit.

Build 60 · v1.8.1 · MTMA numeric + Google login vs invite (Loki · build pulled de la el)

Changelog

  • Câmp MTMA: doar cifre / separatori de masă la tastare (sanitizeMmaInput) — literele nu mai apar în casetă.
  • Google pe Login: dacă domeniul firmei e deja pe Transitix dar mailbox-ul nu, răspunde GOOGLE_NEEDS_INVITE (cere invitație) în loc să forțeze o firmă nouă; legare și pe google_sub.

Build 59 · v1.8.0 · Profil OCR carnet de bord

Changelog

  • Profil nou carnet_bord: etichete tipărite de mână (TIP MARFĂ, CANT MARFĂ, NR. CURSE, RUTA TRANS., DATA, TPO cu OCR greșit TP0/IPO).
  • Ruta pe 2+ linii (origine + adresă livrare cu săgeată); cantitate 15,744,00 fără a schimba parseNumber global.
  • numar_curse ajunge pe document (inclus în EXTRACT_COLUMNS).

  • Unitatea cantității nu mai sare pe linia următoare (NR din NR. DOCUMENT pe anexă).

Build 58 · v1.7.10 · Google Auth CORS + env Resend/Google (Loki · build pulled de la el)

Changelog

  • CLIENT_ORIGIN acceptă listă separată prin virgulă (ex. localhost + 127.0.0.1 pentru companion local) — CORS nu mai blochează unul din cele două host-uri.
  • Env example: documentat OAuth Web Client ID (nu Firebase) + Resend pentru invitații / reset / verificare.

Bugfix

  • Google sign-in eșua local când origin-ul din browser nu era exact cel din CLIENT_ORIGIN (localhost vs 127.0.0.1).

Build 57 · v1.7.9 · OCR — drop_score 0.10 + pass scan

Changelog

  • drop_score default 0.10 (era 0.35) — scrisul de mână nu mai e șters după recunoaștere.
  • Pass nou scan_like_document: deskew pe liniile carnetului, ștergere linii (păstrează literele), binarizare.
  • Env pe compose companion + paddle; teste + README.

Bugfix

  • După det 1920, Paddle tot putea întoarce gol: filtrul de încredere pe linie (0.35) arunca textul handwriting citit la 0.1–0.3.

Build 56 · v1.7.8 · OCR — detector 1920px + ink illuminant-invariant

Changelog

  • det_limit_side_len = 1920 (era 960 implicit Paddle) — scrisul de mână nu mai e strivit la ~22px.
  • Preprocesare: fit_for_detector redimensionează o dată la mărimea pe care o citește detectorul.
  • emphasize_ink: gray-world + împărțire la blur local (nu min(R,G) pe fundal verde).
  • bench.py + note README pentru măsurat pe poze reale; env pe compose companion + paddle.

Bugfix

  • Carnet tot gol după ink/perspectivă: upscale-ul era anulat de capul Paddle la 960px — liniile de mână rămâneau sub pragul de detecție.

Build 55 · v1.7.7 · OCR foto — corecție perspectivă

Changelog

  • Pe poze (carnet / telefon): înainte de ink/OCR, detectează colțurile paginii și warpează la dreptunghi (OpenCV).
  • Scanuri full-bleed / fără pagină clară: fără warp fals. Oprire cu PADDLE_OCR_PERSPECTIVE=0.

Bugfix

  • Telefon oblic pe carnet: liniile rămâneau strâmbe și detecția Paddle rata scrisul — acum pagina e frontală înainte de citire.

Build 54 · v1.7.6 · OCR carnet — ink întâi + detecție mai sensibilă

Changelog

  • Pozele (carnet / telefon): întâi upscale + cerneală albastră, apoi rotații — nu mai arde timpul pe raw gol.
  • Paddle: prag detecție mai jos (cerneală slabă pe hârtie), timeout interactiv 120s (era 45s).

Bugfix

  • Poze de carnet pe fundal de monitor tot nu extrăgeau nimic: raw RGB era gol, timeout-ul oprea înainte de pass-urile utile, iar detecția Paddle ignora trasăturile fine.

Build 53 · v1.7.5 · OCR foto carnet (citire goală)

Changelog

  • Dacă Paddle întoarce gol / text foarte scurt pe o poză, rulează totuși enhance, upscale, umbră, CLAHE și un pas care scoate cerneala albastră de pe hârtie (util la carnet pe fundal de monitor).

Bugfix

  • Pe poze de carnet (scris de mână), când prima citire era goală, pipeline-ul oprea pass-urile foto — rămânea „nimic extras”. Acum gol = încearcă mai departe.

Build 52 · v1.7.4 · OCR pe imagine curată + rută Site → livrare

Changelog

  • Paddle citește întâi imaginea curată; contrast / sharpen (pentru poze de carnet) doar dacă lipsesc coduri sau plăcuța — nu pe fiecare pagină.
  • Scan PDF: DPI implicit 280 (era 200), ca textul mic de pe aviz să rămână lizibil.
  • Ruta pe anexă: Site (Bol/Mil) → Adresa de livrare; matcher-ul „oraș-oraș” nu mai ia localități cu cratimă lipită drept rută.

Bugfix

  • După optimizările pentru scris de mână, preprocessarea agresivă pe toate paginile înrăutățea OCR-ul pe avize tipărite / scanuri (mai slab decât cu câteva build-uri în urmă).
  • Ticket 35: export cu Bolintin-Deal în loc de adresa de livrare (ex. Dobroești) — simptom al matcher-ului de rută + câmp ne-gol pe care repair-ul nu îl mai corecta.
