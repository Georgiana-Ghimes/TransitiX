Changelog de testare pentru RAI Spedition — Documente (nu Transitix TMS complet). Versiune companion: v1.3.0 · build 33. Document local — docs/ nu e pe GitHub.

De ce: pe companion, Setări era o pagină lungă cu trei carduri, iar Utilizatori ocupau o intrare separată în sidebar. Acum tot ce ține de administrarea firmei e într-un singur ecran, pe taburi — meniul lateral rămâne pe Avize / Rapoarte / Setări.

CHANGELOG

Setări pe taburi

  • Date companie — denumire, CUI, adresă, contact, TVA, monedă.
  • Notificări expirare — praguri alerte (30 / 15 / 7 / 1 zile).
  • Sesiuni active — dispozitive autentificate + „Închide toate”.
  • Utilizatori — invitații, roluri, legare șofer (doar admin).
  • Tab-ul activ e în URL (/settings?tab=users) — bookmark și refresh păstrează tab-ul.
  • Butonul Salvează setările apare doar pe Date companie și Notificări expirare (sesiunile și utilizatorii au acțiunile lor).

Meniu lateral companion

  • Intrarea Utilizatori scoasă din sidebar.
  • Nav companion: Avize / Rapoarte, Rapoarte, Setări (admin).
  • /users redirecționează la /settings?tab=users — linkurile vechi rămân valide.

BUGFIX

Nicio remediere separat de reorganizarea de mai sus.

Testare rapidă

  1. Login admin → sidebar: doar Avize, Rapoarte, Setări (fără Utilizatori).
  2. Setări → taburi: Date companie, Notificări expirare, Sesiuni active, Utilizatori.
  3. Tab Utilizatori → invite / rol / legare șofer funcționează.
  4. Deschide /users → land pe Setări, tab Utilizatori.
  5. Login / topbar: v1.3.0 - build 33 (după restart Vite).
