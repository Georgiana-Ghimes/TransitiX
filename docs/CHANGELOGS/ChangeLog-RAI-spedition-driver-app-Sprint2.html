OCR — Paddle unic

  • Google Vision eliminat — un singur pipeline: PDF text layer → PaddleOCR local.
  • Același flux pentru upload șofer, loturi birou și Re-extrage pe /avize.
  • GET /api/health raportează ocr: paddle / paddle-down / false.
  • Banner pe /avize când Paddle e configurat dar containerul nu răspunde.
  • După upload șofer: OCR doar pe documentele noi; timeout 5 min pe CPU VM; lock per batch.

App șofer — UX upload

  • Avertisment blur înainte de trimitere (heuristică Laplacian) — poți refotografia sau trimite oricum.
  • Throttle client (20/min) înainte de limita serverului — mesaj cu secunde rămase.
  • Polling listă „Trimise recent” la 8s cât timp status = Încărcat (doar tab vizibil).
  • Verificare număr fișiere (max din API) și 15 MB înainte de upload.
  • Mesaje eroare în română (nu „Failed to fetch” / „Unexpected field”).

Deploy VM și acces colegi

  • 3 terminale dev: API, UI companion, cloudflared spre Vite.
  • Quick tunnel Cloudflare (*.trycloudflare.com).
  • Vite allowedHosts pentru tunnel; proxy API implicit 3002 în mod companion.

  • Host *.trycloudflare.com respins de Vite — adăugat în allowedHosts.

OCR rămânea pe „Încărcat”

  • Batch deschis: OCR reprocesa toate pozele vechi înainte de cea nouă.
  • Timeout 2 min tăia Paddle pe rotații CPU.
  • Remediat: OCR doar fișiere noi, timeout 5 min, erori per-document nu blochează batch-ul.

Re-extrage pe /avize golea câmpurile

  • Butonul folosea Vision/stub când nu exista cheie Google — acum același Paddle ca upload-ul șoferului.

Testare rapidă (VM companion)

  1. docker compose -f docker-compose.companion.yml up -d --build
  2. cp server/companion.env.example server/.env · migrate · seed
  3. Dev: npm run dev --prefix server + npm run dev:companion + cloudflared
  4. Demo VM: npm run start:companion (un singur port API + UI build)
  5. Health OCR: curl http://127.0.0.1:3002/api/health → capabilities.ocr
  6. Login șofer → upload aviz → admin /avize (filtru „De la șofer”)
