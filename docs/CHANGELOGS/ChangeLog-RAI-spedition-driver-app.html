Fluxul end-to-end a fost verificat manual: upload din driver → extracție → vizibil în admin cu sursă paddle / uploaded_from: driver.

3. Specificații tehnice

3.1 Arhitectură OCR

ComponentăDetaliu
Serviciu tools/paddle-ocr/ — FastAPI + PaddleOCR 2.9 / paddlepaddle CPU, Python 3.10
Compose docker-compose.paddle-ocr.yml → host 127.0.0.1:8100
API Transitix server/src/lib/ocr/readText.js — PDF text → Paddle → (opțional Vision fallback)
Extracție câmpuri profiles.js + fields.js + extract.js; normalizare normalizeOcrText.js
Env OCR_PROVIDER=paddle, PADDLE_OCR_URL=http://127.0.0.1:8100 (server/.env.example)
Auto-rotate PADDLE_OCR_AUTO_ROTATE=1 (default); early-exit doar dacă există deja TPO/PSL/TRO pe 0°

4. Limitări cunoscute (momentan)

LimitareImpactDirecție viitoare
Scris de mână românesc (cursiv + diacritice) Proza („Adresă”, „Placuță…”) rămâne slabă; codurile/plăcuța se salvează mai bine după rotație + normalize TrOCR (self-hosted) sau Vision fallback pe poze slabe
Paddle pe CPU, fără GPU Primul OCR / rotații multiple: mai lent GPU image sau early-exit agresiv (deja pe printat cu PSL/TPO)
PDF scanat ca PDF (fără text layer) Paddle path din Node sare peste PDF raw; rămâne text layer sau Vision PDF→imagine înainte de Paddle
Șoferul nu vede încă câmpurile extrase Doar listă fișiere / status; review-ul e în admin Template / review pe telefon (cerință viitoare)
Listă driver nu re-poll după OCR async Poate rămâne „Încărcat” până la refresh Polling scurt sau websocket
Docker Desktop obligatoriu pentru OCR local Fără daemon → Paddle down; upload tot reușește, extracție goală/slabă Health-check în UI admin / alertă
API tests pe DB de test Necesită TEST_DATABASE_URL=…_test Documentat în seed / CI

5. Cum se pornește local

  1. Docker Desktop pornit
  2. docker compose -f docker-compose.paddle-ocr.yml up -d
  3. Health: http://127.0.0.1:8100/health
  4. npm run dev (Vite :5173) + npm run dev în server/ (:3001)
  5. Login șofer: sofer@transitix.ro / sofer123 → /driver-app
  6. Login admin: admin@transitix.ro / admin123 → /avize (filtru „De la șofer”)
