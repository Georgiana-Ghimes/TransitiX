# 1.1.4 — Confirm dialogs for list actions

## What changed

Replaced native browser `confirm()` with the shared in-app `ConfirmDialog` on:

| Page | Action | Variant |
|------|--------|---------|
| Curse (`Trips.jsx`) | Șterge | danger |
| Șoferi (`Drivers.jsx`) | Dezactivează | warning |
| Clienți (`Clients.jsx`) | Dezactivează | warning |
| Depozit (`Warehouse.jsx`) | Șterge | danger |

Success/error feedback uses toasts (`notifySuccess` / `notifyError`), consistent with Flotă.

## How to verify

1. Run UI on `http://127.0.0.1:5173/`
2. **Curse** → Șterge → styled modal (not browser alert) → confirm → toast + row gone
3. **Șoferi** → Dezactivează → warning modal → confirm → toast + status updated
4. **Clienți** → Dezactivează → same pattern
5. **Depozit** → Șterge → danger modal → confirm → toast + product gone
6. Cancel / Escape / backdrop should dismiss without action while not busy
