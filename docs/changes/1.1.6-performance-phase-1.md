# 1.1.6 — Performance phase 1

## What changed

### Frontend
- Route code-splitting: GPS (Leaflet), Planning, Finance, DriverApp, Documents load on demand
- Main bundle ~254 KB (was ~1 MB monolith); Recharts/Leaflet in separate chunks
- GlobalSearch hits `GET /api/search?q=…` (debounced) instead of downloading 700 entities
- React Query default `staleTime: 60s` for future shared caching
- NotificationBell polls every 2 min only when tab is visible

### Backend
- Notification computed alerts: expiry rows filtered in SQL + 5 min in-memory cache
- `markAllComputedRead`: single batch upsert
- New indexes (run `npm run db:migrate`)
- `compression` middleware, smaller default JSON body limit
- Pool config in `server/src/db.js`

## Verify

```bash
npm run db:migrate
npm test
npm run build   # check dist/assets/index-*.js ~250KB
```

2. Global search: type 2+ chars — network shows `/api/search` not 3 large list calls
