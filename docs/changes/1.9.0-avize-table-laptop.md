# 1.9.0 — Avize table on small laptops

**Branch:** `RAI-spedition`

## What changed

The Avize list used `table-fixed` with `min-w-[860px]` and **no width on Rută**. On a 13" Mac at 100% zoom (content area ~1000px after the sidebar), the leftover Rută column collapsed to ~0 and the **Rută** / **Marfă** headers painted over each other. Acțiuni was also clipped.

- Every column has an explicit width (Rută `16rem`, Acțiuni `14rem`)
- Table `min-w-[82rem]` so `overflow-x-auto` scrolls instead of squeezing
- Cards stay until `lg` (1024px), not `md` (768px)
- Action links wrap instead of overflowing the cell

## Verify

1. Open `/avize` at 100% zoom on a ~13" laptop (or DevTools ~1280×800 with the sidebar open).
2. Rută and Marfă headers sit in separate columns; route text truncates with a tooltip, cargo stays under Marfă.
3. If the window is still tight, the table scrolls horizontally; it does not overlap.
4. Below 1024px width, the card list still shows route + cargo stacked.
