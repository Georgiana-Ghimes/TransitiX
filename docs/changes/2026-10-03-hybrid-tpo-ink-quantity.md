# TPO pe cerneală color + Cantitate ≠ greutate

- PDF cu TRO/PSL dar fără TPO în text layer → OCR pe pagină (cerneala de mână), text OCR + layer îmbinate.
- Poze: ink → negru + grayscale + contrast înainte de upload.
- Cantitate: refuză „Cantitate … kg” când e de fapt greutatea de pe cântar; preferă `72.00 buc`.
