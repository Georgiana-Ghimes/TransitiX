# 1.1.5 — Unit tests + CI

## What changed

- **Vitest** suite covering shared frontend helpers, toast reducer, server entity mapping, and JWT auth middleware
- **GitHub Actions** workflow (`.github/workflows/ci.yml`) runs on every push/PR to `main`: lint → unit tests → frontend build
- **Șoferi**: inactive cards show Reactivează / Șterge (Flotă parity)
- **Toasts**: 3s auto-dismiss, progress bar, smooth fade, max 3 visible
- **`npm run db:seed:fleet`**: re-runnable dummy data for Flotă / Șoferi / Clienți

## Verify locally

```bash
npm ci
npm ci --prefix server
npm test
npm run lint
npm run build
```

## Verify CI

Open a PR to `main` — the **CI** check should pass (lint, test, build).
