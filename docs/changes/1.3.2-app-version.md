# 1.3.2 — App version in UI + auto-semver

## What changed

- Office sidebar footer and auth pages (login / register / reset) show `vX.Y.Z` from `package.json`.
- A `post-commit` git hook bumps root + `server/package.json` together after each commit:
  - `feat:` → minor
  - `feat!:` / `BREAKING CHANGE` → major
  - anything else → patch
  - skip with `[skip version]` in the commit message

## Verify

1. `npm run prepare` (installs `.git/hooks/post-commit`).
2. Login page and sidebar footer show `v1.3.2`.
3. Make a local commit like `fix: example` — version becomes `1.3.3` in the same commit (`git log -1 --stat` includes both `package.json` files).
