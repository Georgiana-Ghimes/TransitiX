# #66 reopen — CMR pe /avize (WA0041)

## Problemă

Scrisoare de trăsură CMR (IMG-20261005-WA0041): rută doar expeditor, tip m³ / cantitate 18 pal, greutate brută goală — deși pe pagină sunt Ploiești→Giurgiului, 720 saci, 14 844 kg.

## Cauză

OCR Mistral pune antetele `3 Locul…` / `6…7…11…` pe o linie și valorile pe următoarea (`720 18 pal. saci … 14 844`), fără `7.` / `11.`. Parserul aștepta `N.` ca la carnet.

## Remediere

- Box tipărit cu spațiu (`3 Locul`), box 4=încărcare / box 3=livrare
- Grid 6–12: cantitate 720 (nu 18 pal), tip saci (nu m³ din volum), brută `14 844`
