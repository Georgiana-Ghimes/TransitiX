# 1.7.1 — Version in the running app

## What

The UI and API now read the semver from `package.json` (not a Vite define frozen at `npm run dev` start). Sidebar, login, driver footer, browser tab, and `GET /api/health` all show the same version.

## Verify

1. Refresh http://127.0.0.1:5173/ — tab and sidebar footer show `v1.7.1`.
2. Login page shows `v1.7.1`.
3. `GET /api/health` includes `"version": "1.7.1"`.
