# 1.8.2 — P1 Avize UX polish

## What changed

- **Bulk confirm spam prevention**
  - `Confirmă selectate` is now disabled unless at least one selected row is not yet `confirmed`.
  - The bulk confirm handler only calls the endpoint for non-`confirmed` rows and uses an in-flight lock to prevent duplicate submissions.
- **Bulk heavy actions de-duplication**
  - `Unește (export XLSX)` and `Zip` now set `busy=true` and are disabled while the request is running, preventing multiple exports/zips from rapid clicking.
- **PDF preview polish**
  - Improved desktop preview styling (remove iframe border, add white background) and increased preview height so it better matches the modal area.
- **Preset UI**
  - `Azi / Săptămâna asta / Luna asta` now shows an active visual state and `Resetează` clears it.

## Verify

1. Select a mix of `uploaded/extracted` and confirm them with **Confirmă selectate**.
2. Try spamming **Confirmă selectate** after the first confirmation — no new `POST /api/avize/bulk-confirm` requests should be sent.

4. Open **Editează** on a PDF on desktop — preview should be taller and look cleaner.
5. Click **Azi / Săptămăna asta / Luna asta** and then **Resetează** — active styling should update.
