# 1.3.1 — Uploads auth, driver ACL, lost-update races

Patch for High findings and lost-update races. **Do not push until you have smoke-tested locally.**

## What

- **Uploads:** `GET /uploads/:filename` requires JWT. `<img>` uses `?access_token=` via `withAccessToken()` (DriverApp / TripDetail).
- **Driver ACL:** entity routes check `entityAllowedForRole`. Drivers keep Trip / TripDocument / Chat / DriverNotification / self Driver. Trip PUT is `DRIVER_TRIP_WRITABLE` only.
- **Global email:** unique index `users_email_lower_uniq`; register is one transaction; `23505` → 409.
- **Avize:** re-extract `mergeReextractRow` + keep Confirmat; repair skips no-op writes; templates use `FOR UPDATE` on the company row; filenames get a UUID.
- **Other races:** warehouse `quantity = GREATEST(0, quantity + delta)`; password reset consumes the token in one `UPDATE … RETURNING`; confirm `WHERE status = 'pending'`; GPS simulate one transaction; dispatcher omits unchanged trip status.
