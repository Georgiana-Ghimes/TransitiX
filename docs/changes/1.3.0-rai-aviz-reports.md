# 1.3.0 — RAI Avize / Rapoarte

## What

New office page **Avize / Rapoarte** (`/avize`) for RAI Spedition: turn Baumit-style avize (PDF or photo) into an **Anexa Factura RAI** XLSX.

- `POST /api/avize/extract` — PDF text layer, else Google Vision, else empty stub for manual fill
- `POST /api/avize/export` — selected rows + template → `.xlsx` (yellow header)
- Default template **Anexa Factura RAI** seeded per company (14 columns)
- Tables `report_templates` and `aviz_documents` (company-scoped)

Do not commit client PDFs/xlsx (PII). Parser tests use synthetic PSL + TRO fixtures.

## Verify

```bash
npm run db:migrate
npm test
npm run lint
npm run build
```

1. Log in as admin → **Avize / Rapoarte**
2. Upload a PSL and a TRO aviz (PDF with text works without Vision)
3. Refresh Avize / Rapoarte — TPO should be `TPO-00…` (not MPI / Adeziv)
4. Confirm rows, click **Unește în Anexa XLSX** — file should have 14 columns like the client annex
5. **Ruta transport** is Client (start) → Adresă de livrare (end), e.g. `Bucuresti/Aeroportului120-T-Bucuresti/Viilor52`. It must not be `Bol-Bolintin` or `Bol-Bucuresti/Viilor52` from the Expeditor plant. Site BOL/MIL is only used when there is no Client street (TRO transfers).
6. **Numar auto** can be two plates (`B-112-VFM / B-475-AGR`). Missing plates stay empty (`—`), never the full PDF text.
7. **Editează** must persist date, auto, rută, and document number after save and refresh. Page load no longer re-parses the PDF over office edits. Use **Re-extrage** to take values from the file again.
8. The Avize toolbar keeps Încarcă, Foto, the template select, and Unește on the same top edge; the template hint sits under the dropdown only.
9. The Avize table must stay inside the page: long Auto/Rută values truncate with a tooltip.
10. **Legendă acțiuni** under the toolbar explains Confirmă / Re-extrage / Editează / Șterge / Unește. Tab **Șabloane**: the dropdown on Avize is what export uses; “implicit” is the preselected template.
11. After editing a template (e.g. Taxă 100, Tarif km 20), select it in the Avize dropdown and Unește again. Defaults fill Excel when the aviz field is empty or 0. The file name uses the template name (`Sablon_nou-…xlsx`).
12. `npm test` includes `avizExport.test.js`: default RAI sheet (14 columns) and a custom template missing Nr. crt still writes Taxă 100 / Tarif km 20 into the xlsx buffer.
13. Manual evidence checklist: [`docs/changes/1.3.0-avize-manual-checklist.md`](1.3.0-avize-manual-checklist.md)
