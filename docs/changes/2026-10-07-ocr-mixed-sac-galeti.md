# OCR #62: saci + găleți pe același aviz

Pe foi mixte, Tip marfă/Cantitate luau doar sacii (rank maxim); liniile `buc` (găleți) dispar.

- Dacă pagina are atât `sac` cât și `buc`, `buc` = găleți și se adună ambele.
- Tip = `saci/galeti`, Cantitate = suma (fără `pce` paleți euro).
- Exemplu PSL-0062056: 401 + 197 = 598.
