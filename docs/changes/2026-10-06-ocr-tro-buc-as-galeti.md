# OCR #57: Tip marfă gol pe TRO fără „Numărul de găleți”

Pe avizele TRO (UniBaza / SilikoTop / Glet) cantitatea e `N.00 buc`, iar footerul lipsește.
`bucati` nu se scrie pe Tip marfă (nu numește ambalajul), deci câmpul rămânea gol și lista arăta „72 bucati”.

Regulă: `sac` = saci; `buc` pe tabel tipărit (24/pal, Palet Euro, SKU pastă, articol 11… + TRO/PSL) = găleți. Un `Cantitate N buc` izolat rămâne `bucati` pentru revizuire.
