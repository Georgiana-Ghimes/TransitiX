# 1.9.0 — office intro tour (Ghid)

**Branch:** `RAI-spedition`

## What changed

Dispatchers get a short 6-step modal on first office login: what Transitix is, Avize → Anexa (including when Default applies), curse/flotă/șoferi, financiar without ANAF, GPS/Planning as demos, and how to reopen the guide.

- Auto-opens once per browser (`localStorage` key `transitix_office_tour_seen`)
- **Desktop (lg+):** coach panel bottom-right, sidebar/content spotlight, main area dimmed
- **Mobile (&lt; lg):** full-width bottom sheet (portal), shorter text, ☰ hamburger ring on menu steps; drawer stays closed during tour
- **Ghid** in sidebar reopens the tour (desktop + mobile)
- Drivers never see it (no office layout)

## Verify

1. In DevTools → Application → Local Storage, delete `transitix_office_tour_seen`. Refresh while logged in as `admin@transitix.ro`.
2. Step 1: Dashboard is highlighted in the menu; coach panel sits bottom-right.
3. Click **Următorul**: route changes (e.g. `/avize`), matching nav item gets an amber ring; page behind is dimmed.
4. Last step: **Ghid** at the bottom of the sidebar is highlighted.
5. Refresh: tour stays closed. Sidebar **Ghid** opens it again from step 1.
6. Phone: bottom sheet tour; ☰ ring on menu steps; drawer stays closed until the user opens it.
