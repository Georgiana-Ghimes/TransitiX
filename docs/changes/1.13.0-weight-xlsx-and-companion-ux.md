## Verify pe VM

1. `git pull` pe branch, `npm i` dacă e nevoie, `npm run db:migrate` (coloane include_*)
2. Restart API + companion (`:3002` / `:5174` sau stack-ul tău)
3. Editează un aviz Baumit cu ambele greutăți → bifează ambele → Unește → XLSX are Cantitate (tone) + Greutate netă (kg)
4. Debifează netă, salvează, Unește din nou → dispare coloana netă
5. Companion: zoom ~150%, upload Poză/Manual încă încăpătoare
