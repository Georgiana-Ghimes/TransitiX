# 1.1.0 — Responsive sweep + fleet UX

## Summary

Version **1.1.0** packages local bootstrap docs, fleet remove/confirm UX, and a platform responsive pass so office + driver UIs remain usable on common phone/tablet/desktop widths.

## Responsive targets (code-level)

| Breakpoint | Intent |
|------------|--------|
| ~360–480px | Phone portrait — cards, drawer nav, mobile search |
| ~768px (`md`) | Tables appear; cards hide |
| ~1024px (`lg`) | Persistent sidebar; denser padding |
| Desktop | Collapsible sidebar rail |

## Key files

- `src/components/Layout.jsx` — mobile search row, tighter header
- `src/pages/Trips.jsx`, `Finance.jsx`, `Warehouse.jsx`, `Dashboard.jsx` — card vs table
- `src/pages/GPSMap.jsx` — responsive map height
- `src/components/AuthLayout.jsx`, `ModalShell.jsx`, `index.css`, `index.html`
