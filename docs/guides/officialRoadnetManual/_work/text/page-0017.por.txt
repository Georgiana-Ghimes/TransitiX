Nota: A região selecionada como padrão é exibida como tal para o usuário conectado ao

É possível selecionar uma região padrão em qualquer módulo, com exceção do módulo

Para selecionar uma região padrão, clique com o botão direito do mouse no nome da

Alternância de regiões
Às vezes, pode ser necessário alternar de uma região para outra. O Roadnet
Transportation Suíte permite alternar facilmente entre regiões na maioria das áreas do
programa. Como você trabalha com as informações de uma região com mais frequência
do que outras, pode tornar padrão uma região.
Nota: Somente as regiões às quais você tenha acesso no módulo serão exibidas na lista.
Etapa 1: Abra o módulo apropriado.
Etapa 2: No lado inferior direito da barra de status da janela há um campo com o nome
da região atual. Clique na seta e uma lista de regiões será exibida.
Etapa 3: Clique na região com a qual deseja trabalhar. A lista de regiões fecha e uma
janela de confirmação é exibida.
Etapa 4: Clique em [Sim] para alterar para os dados da nova região ou em [Não] para
continvar trabalhando com a região atual.

Como trabalhar com os itens de manutenção
Utilizado com: Roadnet, Territory Planner, FleetLoader, MobileCast
Todos os itens do Roadnet Transportation Suite utilizam janetas de manutenção para a
adição, edição e exclusão de itens. Isso significa que o mesmo processo básico pode ser
vtilizado para a manutenção de todos os itens.
Clique no ícone Manutenção para abrir o respectivo módulo. Em seguida, escolha
adicionar ou atualizar as informações no sistema.
Adição de itens
Cada item de manutenção no Roadnet Transportation Suíte, como equipamentos,
funcionários ou clientes, contém instruções passo a passo específicas sobre como
adicionar informações, uma vez que os dados necessários para cada item são diferentes.
Por exemplo, 2o procurar instruções sobre como adicionar equipamentos, você verá a
seção principal Equipamento, que descreve os conceitos associados aos equipamentos,
seguida das instruções passo a passo para a adição de equipamentos.
Se você estiver adicionando um item semelhante 2 um item existente, é possível clonar o
item existente, reduzindo a quantidade de texto que necessita ser inserido.
