Importação de informações de rotas diárias no MobileCast
Importação de informações de rotas diárias no MobileCast
Utilizado com: MobileCast
Se você estiver utilizando o Roadnet ou o Territory Planner para criar rotas, terá de baixar
as rotas do pacote de roteirização para o MobileCast executando uma importação diária.
A importação diária baixará as rotas do dia, incluindo quantidades de entrega, atribuições
de container (se disponível), qualquer intervalo, espera, pernoite ou depósito
intermediário, pedidos não atendidos, cenários e outras informações necessárias. Rotas
estáticas também podem ser importadas diariamente. Para obter mais informações,
consulte Configuração dos layouts de arquivos de importação, Importação de atribuições
de container ou Importação de rotas estáticas.
. Notas: Se você estiver utilizando o Roadnet ou o Territory Planner para criar rotas, não
precisará importá-las. Basta transferi-las do Editor de roteirização ou do Editor de
Planejamento para o MobileCast. Consuíte Envio de rotas diárias ao MobileCast
u Envio de rotas de planejamento ao MobileCast para obter mais informações.
.Ao importar rotas estáticas ou conjuntos de rotas estáticas, consulte Importação
de rotas estáticas.
Para que as rotas possam ser importadas, todos os status e tipos devem ser
inseridos no MobileCast. Se você importar informações de motoristas e
equipamentos para as rotas, os motoristas e os equipamentos também deverão
S ser inseridos.
Todos as IDs de rota devem estar em letras maiúsculas para fins de importação.
Etapa 1: Clique no ícone Importação para abrir o módulo Importação.
Nota: Se você tiver várias regiões, verifique se a região apropriada é exibida na parte
inferior da tela. Para alterar a região, basta clicar na seta e escolher outra na lista
exibida. O cenário mostrado aqui não é usado durante essa importação.
Etapa 2: Clique no menu Importar e selecione Expedir, Diariamente e Completo. A
janela Importação diária é exibida.
. Notas: O nome do conjunto de layouts atual é exibido na barra de status, na parte inferior
do módulo Importação. Se o conjunto não estiver correto, altere-o antes da
importação. Consutte Altemância entre conjuntos de layouts para obter mais
informações.
Para ver ou alterar o layout do arquivo de importação, clique na seta [Layout do
arquivo] e selecione Editar layout e o nome do layout no menu suspenso.
Consute Configuração de layouts de arquivo de importação para obter mais
informações.
