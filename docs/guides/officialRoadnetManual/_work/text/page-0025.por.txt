A seção Opções de telefone Java permite estabelecer diversas opções padrão ao usar
telefones ativados para java com o MobileCast.
Etapa 12: Se os motoristas estiverem usando telefones ativados para Java para se
comunicarem com o analista e com o MobileCast, marque as opções abaixo
que se apliquem à sua configuração de comunicações.
Monitorar alterações de fuso horário — permite definir se haverá
monitoramento quando um motorista mudar de fuso horário. O telefone
ativado para Java não aftera os fusos horários automaticamente, mas, se essa
opção estiver marcada, o MobileCast poderá informar se o fuso horário local
foi alterado pelos dados de tempo enviados pelo telefone.
Enviar por tempo — permite especificar com que frequência o telefone
ativado para Java envia dados de posição ao servidor. Digite a frequência em
segundos. A menor frequência possível é 60 segundos.
Se essa opção e Enviar por distância estiverem marcadas, os dados de posição
serão reunidos quando qualquer uma das condições for atendida.
Enviar por distância — permite especificar com que frequência o telefone
ativado para Java envia dados de posição ao servidor. Digite a frequência em
milhas. À menor frequência possível é 0,5 milha.
Se essa opção e Enviar por tempo estiverem marcadas, os dados de posição
serão reunidos quando qualquer uma das condições for atendida.
Modo passivo — permite que o MobileCast adicione paradas
avtomaticamente 2 uma rota, à medida que os dados de posição forem
enviados do telefone para o MobileCast. O Modo passivo será utilizado se
Você estiver usando roteirização passiva ou não planejada, a qua! é
conveniente para funcionários como um vendedor, que deseja muito pouca
interação com o telefone ativado para Java.

Tempo máximo de parada — se você marcou Modo passivo, digite o tempo, em
minutos, que o telefone ativado para Java poderá fícar parado antes que o
MobileCast considere o GPS atua! como uma parada ofícial em uma rota. Por
exemplo, se você digitou 10 minutos e um vendedor permanecer no escritório de
um cliente por 10 minutos ou mais, o telefone ativado para Java enviará os dados
da posição atual para o MobileCast e uma parada para a rota desse vendedor será
adicionada automaticamente.

chega ao escritório de um cliente, o MobileCast utilizará os dados de posição
enviados do telefone ativado para Java para indicar todos os clientes em um raio de
