Como agregar sessões de roteirização
Utilizado com: Roadnet
Sehouver mais de um roteirizador criando rotas para a mesma região, pode ser necessário
agregar todas essas rotas em uma única sessão para poder avaliar o quadro do dia
completo, além de imprimir relatórios. Ao agregar sessões, a rotas da sessão de origem
selecionada são adicionadas à sessão de destino existente. À sessão de destino deve estar
no banco de dados com o qual você está trabalhando. À sessão de origem pode vir de duas
Iocalizações diferentes: ela pode ser outra sessão no banco de dados atual, ou se você
estiver utilizando o banco de dados Access, pode ser um banco de dados do arquivo que
você tenha criado.
Para que as sessões sejam agregadas, as seguintes condições devem existir
* aregião para a qual você está importando rotas deve existir no banco de dados no
qual elas estão sendo importadas;
* todosos itens de manutenção (clientes, motoristas, equipamentos, etc.) utilizados nas
rotas devem existir no banco de dados para o qual estão sendo importados;
* se você selecionar Importar arquivo, o arquivo deverá ter sido criado na mesma
versão do Roadnet para a qual está sendo importado.
Você pode agregar as rotas em uma única sessão, no módulo Manutenção ou no Editor de
roteirização.
