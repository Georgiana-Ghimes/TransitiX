Compartilhamento de recursos
Utilizado com: Roadnet, Territory Planner, FleetLoader, MobileCast
Alguns recursos do Roadnet Transportation Suite podem ser compartilhados entre as
rTegiões. Os funcionários (motoristas) e equipamentos adicionados para uma região podem
ser atribuídos a rotas em outras regiões, se forem criados como recursos compartilhados
no módulo Manutenção. É possível até mesmo determinar que regiões terão permissão de
vtilizar os recursos compartilhados. Este recurso permite utilizar um conjunto maior de
opções ao atribuir recursos às rotas.
