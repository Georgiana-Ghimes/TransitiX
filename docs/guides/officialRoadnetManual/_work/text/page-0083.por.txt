Após criar um modelo para horário de rush, você pode criar áreas de horário de rush,

atributos específicos. É possível ter tantas áreas de horário de rush quantas forem
necessárias para cada modelo; as áreas podem até estar sobrepostas. Se você deseja definir
variações de velocidade, alterações de direção ou restrições de percurso em ruas
individuais, é necessário criar caminhos de horário de rush.

e restrições de percurso por tipo de via; as áreas simples permitem definir uma variação
de velocidade para todas as vias da área. Se o modelo para horário de rush for usado com

o RouteNet com os recursos de Horário de rush avançado, você pode criar áreas Simples
