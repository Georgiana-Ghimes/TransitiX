Criação do modelo para horário de rush
A primeira etapa para configurar as informações de horário de rush é criar o modelo para
horário de rush. Para cada modeto para horário de rush, você pode definir até três períodos
detempo distintos, cada um com variações de velocidade separadas e outros atributos. Por
exemplo, é possível definir um horário de rush para a manhã e um para a noite, nos quais
as velocidades são reduzidas, e também um período à meia-noite no qual as velocidades
aumentam.
Os modelos para horário de rush podem ser criados somente no móduto Manutenção,
embora seja possível editar um modelo existente no Editor de planejamento ou Editor de
roteirização.

Administração, não poderá adicionar um modelo para horário de rush.
