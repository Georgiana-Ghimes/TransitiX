Como trabalhar com conjuntos de padrões de atendimento
Utilizado com: Territory Planner
Um conjunto de padrões de atendimento é um grupo de padrões de atendimento utilizado
para definir opções de entrega para as extensões de clientes no Territory Planner. Cada
extensão de cliente está associada a um conjunto de padrões de atendimento que define 2s
possíveis opções de entrega que 2 função Atribuir dias pode escolher ao criar rotas. Como
as frequências de entrega definidas nesses conjuntos têm como base a quantidade
entregue, as extensões de cliente com o mesmo conjunto de padrões de atendimento
podem ter dias de entrega diferentes em sessões de planejamento diferentes. Por exemplo,
"um conjunto pode conter um padrão de atendimento que entrega 100% na segunda-feira
com um nível de quantidade de 0-50 caixas e outro padrão que entrega 50% na quarta-
feira e 50% na sexta-feira com um nível de quantidade de 51-100 caixas. À quantidade
entregue para 2 sessão individual determinará qual padrão de atendimento será utilizado
naquela sessão.
É possível ter um número ilimitado de padrões para cada nível de quantidade, bem como
um número ilimitado de níveis para cada conjunto. É necessário adicionar os padrões de
atendimento antes de adicionar os conjuntos de padrões de atendimento.
