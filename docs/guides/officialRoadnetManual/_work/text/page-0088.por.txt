Etapa 2: Clique no menu Arquivo e selecione Mapa. A janela Mapa é exibida.
Etapa 3: Clique no ícone Editar setores. O cursor muda para um setor com sinal de
adição ao lado do ponteiro, para indicar o modo Adicionar setor. O padrão de
setores padrão será exibido no mapa.
Nota: Se você deseja adicionar um setor a um padrão de setores que não está sendo
exibido como padrão, alterne para o padrão de setor apropriado.
Etapa 4: Clique onde deseja que o setor seja iniciado. Um nó é exibido, marcando o
ponto de início do setor.
Etapa 5: Clique onde deseja que o setor vire. Outro nó é exibido neste ponto, com uma
linha conectando os dois pontos. Esta linha é o timite do setor. Continue
clicando até estar pronto para fechar o setor.
Nota: Não é necessário fechar o setor ao criá-lo. Ao selecionar Concluir setor atual no
menu suspenso, o Roadnet fechará o setor automaticamente para você.
Etapa 6: Clique com o botão direito no mapa e selecione Salvar setor atual no menu que
será exibido. A janela Atributos do setor é exibida. Insira as informações
necessárias e clique em [ K. Consulte Edição dos atributos do setor para
