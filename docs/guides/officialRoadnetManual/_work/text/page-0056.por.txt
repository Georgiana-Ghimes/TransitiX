Como trabalhar com cenários
Utilizado com: Roadnet, Territory Planner, FleetLoader, MobileCast
Os cenários são uma maneira fácil de aplicar alterações às janelas de atendimento, aos
tempos de atendimento e até mesmo aos conjuntos de padrões de atendimento em um
nível global. Os cenários podem ser utilizados para a roteirização no módulo Analista,
para sessões de roteirização no editor de roteirização ou para sessões de planejamento no
editor de planejamento. O Roadnet Transportation Suite é fornecido com um cenário
padrão, que pode ser utilizado para fins gerais. Se você utilizar somente este cenário, não
será necessário fazer nada. Mas se necessitar de um meio de alterar os tempos de
atendimento, janelas de atendimento ou conjuntos de padrões de atendimento
globalmente dentro de uma rota ou sessão, os cenários irão ajudá-lo. Por exemplo, se você
precisa atualizar os tempos de atendimento de uma sessão - para levar em consideração a
meve, por exemplo - você pode criar um novo cenário para atualizar instantaneamente os
tempos de atendimento de cada cliente nessa sessão. O cenário estará disponível para uso
quando necessário, mas a atualização ocorrerá apenas para as rotas desse dia. As sessões
de roteirização subsequentes serão revertidas para o cenário padrão. Outra maneira
comum de usar os cenários é para 2 contabilidade de promotores de vendas, que
frequentemente seguem tempos de atendimento e janelas de atendimento diferentes.
