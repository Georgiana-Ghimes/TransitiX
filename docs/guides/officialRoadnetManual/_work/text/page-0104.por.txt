Importação diária de pedidos
Importação diária de pedidos
Utilizado com: Roadnet
Se você estiver utilizando o Roadnet para criar rotas diárias, terá de importar pedidos
diariamente. O módulo Importação permite estabelecer como as informações dos pedidos
serão lidas durante o processo de importação. Você pode especifícar o layout do arquivo
de importação, invalidar pedidos de clientes específicos para não vê-los no Editor de
roteirização, enviar pedidos de um cliente para outro, gerar automaticamente relatórios
sobre os pedidos do dia, entre muitas outras opções.
. Nota:Ao importar pedidos futuros, você poderá receber um aviso informando que outro
usuário está trabalhando com um ou mais pedidos futuros. Se isso acontecer, você
não conseguirá importar os pedidos futuros enquanto o outro usuário não os tíver
salvado e fechado.
