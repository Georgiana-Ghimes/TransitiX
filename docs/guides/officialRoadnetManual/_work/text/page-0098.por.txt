Nota: Você não poderá abrir este módulo se não recebeu permissão para controlar a

O banco de dados do Roadnet Transportation Suíte contém muitas informações e pode
tomar-se muito grande, consumindo muito espaço em disco. Para ajudar a controlar seu
tamanho, é possível excluir informações do histórico do banco de dados. Entretanto,
certifique-se de que os dados não têm mais valor antes de excluí-los; uma vez excluídos,
os dados não serão considerados ao executar relatórios ou manutenção de tempo de
atendimento.
A Manvtenção do banco de dados executa outra tarefa útil: ela compacta o banco de
dados, para remover todos os registros marcados para exclusão. Ao excluir um item
(cliente, motorista, equipamento, etc.) do Roadnet Transportation Suite, o registro é
marcado para exclusão no banco de dados. Ao executar a Manutenção do banco de dados,
0 programa pesquisa o banco de dados infeiro e remove todos os registros especificados.
