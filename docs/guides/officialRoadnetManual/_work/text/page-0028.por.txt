Tipo de atraso
.A opção Tipos de atraso explica o motivo de o tempo de uma parada planejada não ter
sido cumprido. O tráfego, problemas mecânicos ou situações relacionadas ao cliente são
alguns exemplos de tipos de atraso. Você pode atribuir tipos de atraso no Analista ao
iniciar uma rota, quando uma rota chega em uma parada, parte de uma parada ou quando
arota é concluída. Qualquer tipo de atraso criado fica disponível para todas as regiões. Os
tipos de atraso, usados somente para finalidades de relatório, estão disponíveis somente
se o MobileCast estiver carregado.

Status do funcionário
Os status do funcionário permitem classificar funcionários de acordo com os critérios que
você definir. Você pode utilizar o status para ajudar a determinar que funcionários estão
disponíveis para serem atribuídos a uma rota no Analista. Treinamento ou doença/
deficiência são alguns tipos de status de funcionário. Cada status de funcionário que você
cria é disponibilizado para todas as suas regiões. O Transportation Suíte é fomecido com
dois status de funcionário preenchidos automaticamente: RDY (Pronto) e USE (Em uso).
Manutenção —Cadastros —Funcionários — Status do funcionário
Tipo de funcionário

tipos de funcionário. Consulte Como trabalhar com tipos de funcionários para obter mais
informações. Os funcionários podem ser associados aos tipos quando forem adicionados.

Status do equipamento

pesquisá-los o selecionar equipamentos a serem visualizados. Alguns exemplos de status
de equipamentos são inativo ou pronto. Todos os status de equipamento criados ficam
disponíveis para todas as regiões. O Transportation Suite é fornecido com dois status de
equipamento preenchidos automaticamente: RDY (Pronto) e USE (Em uso).
