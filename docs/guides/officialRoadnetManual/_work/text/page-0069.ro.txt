Cum să lucrați cu dispozitive wireless
Folosit cu: MobileCast
Dispozitivele wireless permit celui de-al doilea driver să comunice direct cu sistemul
de MobileCast, fără a trece prin analist. Pentru a utiliza sistemul wireless, intră șoferul
mesajul de pe dispozitivul wireless și mesajul este transmis automat către
Server MobileCast. Pe server, mesajul este citit și procesat și MobileCast
efectuează automat funcția, cum ar fi finalizarea opririi și informațiile actualizate
poate fi văzut pe ecranul computerului analistului. Dacă MobileCast observă a
problemă cu funcția fiind finalizată atunci când este trimis de șofer, un mesaj
mesajul de eroare este listat în evenimentele wireless, astfel încât analistul să poată verifica evenimentul și să-l editeze.
Primul după cum este necesar, înainte ca MobileCast să actualizeze sistemul. Vezi Cum
lucrați cu evenimente wireless pentru mai multe informații.
Dacă șoferii descarcă rute folosind dispozitive RN Mobile sau
Telefoane compatibile WAP, nu este nevoie să adăugați dispozitive wireless la
MobileCast. Dacă dispozitivul mobil utilizat este un model anterior de tipul respectiv
atribuite rutelor, va trebui să adăugați dispozitivele wireless la MobileCast
așa cum este descris mai jos.
