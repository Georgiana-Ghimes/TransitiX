Inserção de informações de extensão de cliente
A página Extensão do cliente do menu Cliente permite digitar as informações utilizadas
pelo Territory Planner para criar rotas estratégicas. As informações sobre extensão do
cliente são específicas da sessão de planejamento no Territory Planner, portanto você
pode inserir informações diferentes sobre extensões de clientes para as diferentes sessões
existentes. Para cada extensão do cliente, escolha um território, um conjunto de padrões
de atendimento, uma sessão e uma quantidade para o tamanho 1. As informações restantes
são opcionais.
