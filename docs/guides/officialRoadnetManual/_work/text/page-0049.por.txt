Como trabalhar com funcionários
Etapa 9: Insira o endereço e telefone do funcionário. Também é possível inserir as datas
de contratação, nascimento e rescisão.
Ao inserir informações de data, você pode digitar a data ou clicar na seta para
exibir o calendário. Você pode usar os ícones de rolagem no alto da janela do
calendário para percorrer os meses (setas simples) ou anos (setas duplas).
Quando alcançar a data desejada, clique no número dessa data para selecioná-la.
Etapa 10: Digite a senha do funcionário. É possível utilizar letras, números ou sinais de
pontuação. Este campo não necessita ser preenchido, 2 menos que o
funcionário esteja utilizando comunicação sem fio.
Etapa 11: Se você planeja exportar dados de folha de pagamento do MobileCast para a
ADP, é necessário preencher o Número do arquivo ADP com um código de
funcionário válido. Para encontrar esses códigos, verifique seu software ADP.
u entre em contato com a ADP.
Etapa 12: Se o funcionário puder ser utilizado por qualquer outra região, selecione as
regiões na caixa Compartilhado por regiões. Para selecionar mais de uma
Fegião, selecione a primeira região e, em seguida, mantenha pressionada a
tecla [Ctrl] enquanto seleciona as outras.
Etapa 13: Se desejar atribuir um cliente a este funcionário, clique na guia Clientes.
Pesquise os clientes, inserindo o tipo de cliente, ID ou descrição e, em
seguida, clicando no botão [Consuitar]. Os clientes aparecem na lista Clientes
disponíveis. Clique no cliente e, em seguida, arraste e solte-o na lista Clientes
atendidos. Esse cliente está agora atribuído ao funcionário.
Dica: Se você estiver utilizando o recurso OnTrack do MobileCast ou se desejar atribuir
um vendedor a um cliente, será necessário atribuir clientes aos funcionários,
. Notas: Para ver uma lista completa de seus clientes, deixe todos os campos vazios e, em
seguida, clique no botão [Consultar].
Se você não souber a ID, digite o máximo que souber seguido por um asterisco (*), como,
por exemplo, 72*.
Para selecionar mais de um cliente na lista Clientes disponíveis, pressione [Ctrl] e, em
seguida, clique nos clientes. Você pode arrastar todos os clientes selecionados para a lista
Clientes atendidos.
