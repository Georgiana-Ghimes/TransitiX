Adição de caminho do horário de rush
Se você estiver utilizando o RouteNet ou o SuperMatrix para calcular tempos e distâncias
de percurso, você pode defínir os atributos de horário de rush para ruas individuais.
Normamente, 2o definir atributos de horário de rush no nível de rua, seriam definidos os
atributos de um caminho inteiro, como um trecho de reta em rodovia interestadual, em vez
de cada segmento individual da rua. O Transportation Suite permite selecionar segmentos
individuais de ruas ou selecionar um caminho que terá os mesmos atríbutos. Se um
caminho de horário de rush percorre uma área de horário de rush, os atributos do caminho
serão usados nessas ruas; se não for especificado um atributo para um caminho, serão
usados os atributos da área. Por exemplo, você pode criar um caminho de horário de rush
dentro de uma área que possui diferentes restrições de percurso, mas deseja utilizar as
variações de velocidade da área. Neste caso, simplesmente ative as restrições de percurso
do caminho, mas deixe as variações de velocidade desativadas. Se você estiver criando
caminhos, o modelo para horário de rush deve ser utilizado com uma sessão de
roteirização ou planejamento e o RouteNet ou o SuperMatrix como calculadora de tempo/
distância, e também estar usando o Horário de rush avançado. Para criar o caminho de
horário de rush, é necessário criar o modelo para horário de rush.
