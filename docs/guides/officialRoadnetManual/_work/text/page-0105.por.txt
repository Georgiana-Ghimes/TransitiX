Para visualizar um relatório que resuma as informações do layout, incluindo o
nome e o local do arquivo de importação e as posições iniciais e o tamanho de
cada campo, clique na seta [Layout do arquivo] e escolha Visualizar no menu

Etapa 3: A seção Sessões para exibirá automaticamente a data da próxima entrega e as
sessões associadas a essa data. Se você estiver importando pedidos de uma data
diferente, clique na seta Sessões para e escolha a data de entrega correta no
calendário exibido. Essa data será usada desde que não haja outra especificada
no arquivo de importação.
Etapa 4: Clique nas sessões para as quais deseja importar os pedidos. Para selecionar
mais de uma sessão, mantenha a tecla [Ctrl] pressionada ao clicar nas sessões.
Os pedidos serão importados para todas as sessões selecionadas.
Nota: Se não houver sessão para a data selecionada ou se desejar criar uma nova sessão,
clique no botão [Criar nova sessão]. À janela Adicionar sessão de roteirização é
exibida. Para obter mais informações sobre essa janela, consulte Criação de uma
nova sessão de roteirização. Depois que a nova sessão estiver criada e salva, ela
será exibida na lista Sessões para.
Etapa 5: Para remover pedidos existentes ou rotas da sessão antes de importar os novos
pedidos, marque Limpar sessões antes de importar.
Etapa 6: Para definir outras opções de importação (por exemplo, como vários pedidos
do mesmo cliente serão tratados, como tratar novos pedidos em rotas prontas
u os relatórios que deseja imprimir após a importação de pedidos), clique em
[Outras opções]. Consulte Configuração das opções de importação de pedidos
para obter mais informações
Nota: Se você não recebeu permissão para alterar as opções de importação e exportação
no módulo Administração, não conseguirá alterar as opções selecionadas ao
importar pedidos.
Etapa 7: Para executar a manutenção do banco de dados antes de importar pedidos,
clique no botão [Banco de dados]. Consulte Manutenção do banco de dados
para obter mais informações
Nota: Se você não recebeu permissão para controlar a exclusão de sessões de roteirização
no módulo Administração, não conseguirá definir essa opção.
Etapa 8: Clique no botão [Importar] para iniciar o processo de importação. A barra de
andamento exibe o status da importação.
Nota: Depois de importar pedidos, você poderá ver o log de importação de qualquer erro
ocorrido durante o processo. Clique em [Exibir log] ou [Exibir erros).
Etapa 9: Quando a importação estiver concluída, e depois de ver os relatórios, clique na
caixa Fechar.

Configuração das opções de importação de pedidos
|O Roadnet permite configurar como o Importador funciona ao importar informações de
pedidos. Há várias configurações disponíveis para executar ações diferentes áurante o
Processo de importação:
* — escolha combinar ou alterar pedidos de um cliente já existente em uma rota pronta
(uma rota que você já acabou de editar).
* — escolhaalterar pedidos que foram inseridos manualmente.
* — escolhaaplicar a condensação de cliente em mais de uma parada (ou seja, várias
paradas no mesmo local) para que as paradas individuais sejam roteirizadas juntas.
* — designealetra“P” para indicar coletas.
* sevocêestiver importando itens do pedido e tiver configurado equivalências, poderá
tê-las consideradas durante a importação. Escolha o alias de tamanho no qual está a
quantidade original como a Origem e o alias de tamanho no qual será colocada a
quantidade de equivalência como Destino.
* — escolha para bloquear automaticamente os pedidos que estão combinados com
pedidos bloqueados existentes.
* sevocê importar detalhes da SKU e se houver mais de uma ocorrência de uma SKU
em um registro, você poderá optar por ter os campos da SKU totalizados. Se essa
opção não for selecionada, a última ocorrência da SKU no registro determinará o
total dessa SKU.
* — escolha gerar e/ou imprimir automaticamente relatórios de resumo do pedido.
