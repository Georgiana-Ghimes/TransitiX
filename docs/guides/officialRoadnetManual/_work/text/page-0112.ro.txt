Utilização do processo de importação em lote
Utilização do processo de importação em lote
Utilizado com: Roadnet, Territory Planner, FleetLoader, MobileCast
Se você rotineiramente importar uma grande quantidade de pedidos, clientes, rotas ou
outros dados, poderá configurar o sistema para importar automaticamente as informações
em um horário específico. O Roadnet Transportation Suíte inclui um importador em lotes
que permite utilizar arquivos em lote para importar automaticamente quaisquer dados que
possam ser importados manualmente por meio do módulo Importação. Para que o
software importe informações, é necessário configurar as opções de importação para cada
item, permitindo executar facilmente o processo de importação em lote a partir de um
prompt de comando utilizando o executável tsimoApp.exe.
. Nota: Os dados de Agregar a partir de arquivo e do computador de bordo não podem ser
importados utilizando o processo de importação em lote.
As opções de importação são definidas em um arquivo de configuração de importação em
lotee, como essas opções podem variar de um item de importação para outro, é necessário
criar arquivos de configuração separados para cada item. Quando o processo de
importação em lote for executado, o módulo importação procurará esses arquivos de
configuração no diretório definido pela variável de ambiente CFCONFIGPATH. Se essa
variável não existir, o módulo importação utilizará o arquivo de configuração encontrado
no diretório local.
. Nota: Se você estiver utilizando importação em lote automática para importar vários itens
(clientes, pedidos, etc.), será necessário criar uma importação em lote automática
separada para cada item que desejar importar. Por exemplo, você terá uma
importação em lote automática chamada batchImpLocations para importar os
clientes e um segundo arquivo chamado batchImpOrders para importar os pedidos.
Siga as etapas abaixo para configurar o processo de importação em lote. O processo de
configuração precisa ser executado uma vez, embora as informações possam ser editadas
sau schimbat în orice moment înainte de a rula importul în lot.

cpconfigpath. Un exemplu pentru fiecare variabilă și calea acesteia urmează mai jos.
