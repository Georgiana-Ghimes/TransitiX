Geocodificação do cliente
A página Mapa do menu Cliente permite geocodificar o cliente. A geocodificação atribui
uma latitude e uma longitude ao cliente, que são utilizadas ao determinar o tempo de
percurso de suas rotas. Quando a página é exibida, o cliente é mostrado como um alvo
vermelho. A geocodificação é baseada nas informações de endereço fornecidas na página
Atributos.
O endereço do cliente fornecido é exibido na caixa Endereço. O Roadnet Transportation
Suite tenta geocodificar automaticamente o cliente com base nesse endereço. À Qualidade
de geocodificação indica o grau de precisão com o qual o cliente foi geocodificado. Você
pode alterar o endereço do cliente clicando no botão [Editar]. Depois de alterar o
endereço, você tem a opção de fazer com que o Roadnet Transportation Suite tente
geocodifícar o cliente novamente.
-A caixa Segmento de rua mais próximo exibe o segmento de rua no qual o cliente está
realmente geocodificado, com base nos dados do mapa do Roadnet Transportation Suite.
Seo cliente não estiver geocodificado em uma rua, o Segmento de rua mais próximo será
o segmento de rua mais próximo em que o cliente está geocodificado.
Se o cliente não for geocodificado automaticamente, você pode pesquisar o banco de
dados para encontrar uma correspondência mais próxima do cliente, ou ainda mover o
mapa para encontrar o geocódigo correto para o cliente. Execute as etapas a seguir para
geocodifícar o cliente manvalmente.
