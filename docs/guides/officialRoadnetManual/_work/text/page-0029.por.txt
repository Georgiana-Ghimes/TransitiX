Tipos de cliente
Tipos de cliente permite a especificação dos tipos de clientes existentes. Normalmente, o
tipo de cliente é simplesmente uma ID e uma descrição, e você pode atribuir os tipos aos
seus clientes para distinguir os depósitos de clientes e de fornecedores, separar
departamentos em um supermercado — inúmeras utilizações. Se você estiver utilizando
tipos de clientes para diferenciar os diversos departamentos de uma única loja, como um
supermercado, é possível fazer com que o Roadnet Transportation Suite sincronize
avtomaticamente os campos selecionados para cada tipo ao adicionar ou editar um cliente;
consulte a página Clientes de Configuração dos padrões para obter mais informações. Se
estiver utilizando a parte de contabilidade do MobileCast, é possível atríbuir um tipo de
monitoramento 2 um tipo de cliente, para diferenciar o custo de entrega em diferentes
tipos de clientes. O Roadnet Transportation Suíte é fornecido com dois tipos de clientes
padrão: depósitos (DPT) e fábricas (SIT), mas você pode adicionar quantos forem
mecessários.
Manutenção — Cadastros — Clientes —Tipos de cliente
Tipos de embalagem
Os tipos de embalagem definem os vários tipos de embalagem carregadas no
equipamento, como latas de refrigerante de 350 m! ou garrafas de 2 litros. Os tipos de
embalagem são utilizados para definir a capacidade de um palete/compartimento ou de
uma camada em um palete. Depois que os tipos de embalagem e as marcas de SKU forem
inseridos, as SKUs poderão ser adicionadas. Se você adquiriu o FleetLoader, você deve
inserir os tipos de embalagem para determinar como seu equipamento será carregado. Os
tipos de embalagem serão usados somente se você adquiriu o Fleetl.oader ou se pretende
importar detalhe do nível de SKU para o arquivo de pedido. Consuite Como trabalhar com
tipos de embalagem para obter mais informações.
Manutenção — Cadastros > Produto — Tipos de embalagem
Tipos de produto
Os tipos de produto são atribuídos às SKUs, e classificam as SKUs com base no tipo de
compartimento em que elas podem ser carregadas. Alguns exemplos de tipos de
produtos são congelados ou refrigerados. Os tipos de produtos serão usados somente se
for utilizada roteirização de compartimento.
Manutenção — Cadastros — Produto — Tipos de produto

Status da rota
Os status da rota podem ser usados para classifícar as rotas de acordo com a urgência, o
estágio de conclusão ou com algum outro critério. Alguns exemplos de status de rota
podem incluir atrasada ou sem status. Os status de rota são atribuídos às rotas no Analista.
Todos os status de rota criados ficam disponíveis para todas as regiões. Essa opção está
disponível somente se o MobileCast estiver carregado.
Manutenção — Cadastros — Rotas — Status da rota
Tipo de motorista
Os tipos de motorista permitem categorizar os motoristas e monitorar as taxas de
pagamento através dessas categorias. Por exemplo, é possível usar um tipo de motorista
para motoristas experientes e outro para novos motoristas, e atribuir uma taxa de
pagamento a cada tipo. Os tipos de motorista são mantidos no módulo Manutenção, mas
como envolvem informações de folha de pagamento, é necessário possuir permissões de
contabilidade para trabalhar com os tipos de motorista.
Manutenção —Cadastros — Funcionários — Tipos de motorista
Tipo de monitoramento
Os tipos de monitoramento são utilizados para controlar informações contábeis e
operacionais, que podem ser combinadas a dados de rotas específicas para produzir
relatórios de contabilidade detalhados. Os tipos de monitoramento são mantidos no
módulo Manutenção, mas como envolvem informações financeiras, é necessário possuir
permissões de contabilidade para trabalhar com os tipos de monitoramento. Consute
Como trabalhar com tipos de monitoramento para obter mais informações. Esta opção
está disponível somente se o MobileCast estiver carregado e você possuir permissões de
contabilidade.
Manutenção > Cadastros * Expedir > Tipos de monitoramento
