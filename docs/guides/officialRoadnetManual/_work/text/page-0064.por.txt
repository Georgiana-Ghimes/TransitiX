Como trabalhar com códigos de detalhes financeiros do pedido
Utilizado com: MobileCast
Se você estiver monitorando informações financeiras sobre seus pedidos, poderá
configurar códigos financeiros que o analista pode aplicar a qualquer pedido. O analista
pode adicionar, editar ou excluir qualquer detalhe financeiro associado a um pedido,
incluindo esses códigos financeiros. Os pedidos associados a esses códigos podem ser
vistos também em um dispositivo portátil, possibilitando ao motorista exibir as
informações financeiras do cliente pertencentes a uma entrega específica.
Etapa 1: Clique no ícone Manutenção para abrir o respectivo módulo.
Etapa 2: Clique no menu Cadastros, selecione Expedir e Códigos de detalhes
financeiros do pedido. A janela Códigos de detalhes financeiros do pedido é
exibida, listando os códigos de detalhes financeiros existentes.
Nota: Para ver uma lista atualizada de tipos financeiros, clique no ícone Atualizar; a
janela será atualizada com todas as informações alteradas do banco de dados.

Débito — O custo original do pedido, somado a quaisquer itens que afetarão o
custo original do pedido, geralmente na forma de um imposto ou uma taxa de
envio.

Como trabalhar com códigos de status do pedido
Como trabalhar com códigos de status do pedido
Utilizado com: MobileCast
Se você estiver utilizando dispositivos portáteis e deseja atribuir o mesmo código a todos
os pedidos de uma parada, é possível criar códigos de status de pedido para que o
motorista possa aplicá-los em diversas situações. Por exemplo, você pode configurar
códigos para serem aplicados pelo motorista quando um pedido é danificado, apresenta
impossibilidade de entrega, é recusado, quando uma parada é cancelada, quando a janela
de atendimento foi perdida, quando a parada exige uma assinatura e assim por diante.
Esses códigos são muito semelhantes aos códigos de motivo, de cancelamento de parada,
de impossibilidade de entrega na parada e de assinatura. À única diferença é que são
aplicados a cada pedido de uma parada.
Etapa 1: Clique no ícone Manutenção para abrir o respectivo módulo.
Etapa 2: Clique no menu Cadastros, selecione Expedir e Códigos de status do pedido. À
janela Códigos de status do pedido é exibida, listando os códigos de status do
pedido existentes.
