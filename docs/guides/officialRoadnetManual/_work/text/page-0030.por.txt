Os tipos de compartimentos são utilizados no setor de bebidas para definir os tipos de
compartimentos disponíveis no equipamento. O Fleetl.oader utiliza informações de tipos
de compartimento ao determinar a quantidade de produto que pode caber em um dado
compartimento. Como os tipos de compartimentos são utilizados somente para
determinar a quantidade de um tipo de embalagem que pode ser carregada nele, é
mecessário criar tipos somente para compartimentos com capacidades diferentes, embora
Yários compartimentos de um tipo possam ter dimensões levemente diferentes. Os tipos
de compartimento devem ser adicionados antes que os tipos de equipamento possam ser
adicionados.
