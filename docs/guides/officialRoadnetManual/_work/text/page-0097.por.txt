Como trabalhar com o gráfico
Além de manipular as caixas de dados 2o lado do gráfico, você também pode alterar as
informações do próprio gráfico. Os itens listados a seguir explicam as diversas maneiras
em que se pode acessar esses elementos de dados.
Para atterar o tempo de atendimento real de uma parada, clique com o botão direito na
parada que deseja editar; a janela Entrada real de parada é exibida. Edite o tempo de
atendimento e as quantidades conforme necessário, e clique no botão [OK] para aplicar.
Você também pode alterar o tempo de atendimento de uma parada, clicando e arrastando
a parada para um novo ponto no gráfico.

Manutenção do banco de dados
Utilizado com: Roadnet, Territory Planner, FleetLoader
(Como o Roadnet Transportation Suíte armazena dados do histórico de roteirização, seu
banco de dados pode ficar muito grande. À Manutenção do banco de dados ajuda a
controlar o tamanho do banco de dados, arquivando ou até mesmo eliminando dados
desnecessários. Você pode selecionar facilmente uma única sessão ou faixa de datas a
serem arquivadas ou excluídas.
.A Manutenção do banco de dados também executa outra tarefa útil: ela compacta o banco
de dados, para remover todos os registros marcados para exclusão. Ao excluir um item
(cliente, motorista, equipamento, etc.) do Transportation Suíte, o registro é marcado para
exclusão no banco de dados. Ao executar a Manutenção do banco de dados, o programa
pesquisa o banco de dados inteiro e remove todos os registros especificados.
Antes de iniciar a manutenção do banco de dados, determine que opção é mais adequada
às suas necessidades atuais. As seções a seguir contêm instruções detalhadas para utilizar
cada opção. Clique em uma opção para obter instruções detalhadas sobre seu uso.
Ferramentas/Manutenção do banco de dados/Arquivar sessões de
roteirização captura uma “imagem” do banco de dados a partir de uma sessão
u data especificada. A função de arquivamento normalmente é usada se você
observar um problema em um dia de roteirização específico e necessitar enviar
essas informações à UPS Logistics Technologies. Todas as informações
necessárias para exibir a roteirização da sessão ou datas especificadas são
incluídas no arquivo. Essa opção estará disponível somente se você estiver
utilizando o Microsoft& Access.
Ferramentas/Manutenção do banco de dados/Excluir sessões de
roteirização remove do banco de dados todos os registros que ocorreram
durante um número especificado de dias, semanas ou meses antes da sessão de
roteirização atual, ou dentro de um intervalo de datas especificado.
Ferramentas/Manutenção do banco de dados/Excluir conf.
automaticamente permite especifícar se a exclusão deve ocorrer
automaticamente durante o processo de importação de pedido, e controlar que
funções ocorrem automaticamente.
Ferramentas/Compactar banco de dados permite reduzir o tamanho do
banco de dados. Ao executar a função Compactar banco de dados, os itens
marcados para exclusão são permanentemente removidos do banco de dados.
