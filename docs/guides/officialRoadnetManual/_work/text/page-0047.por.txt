Como trabalhar com conjuntos de habilidades
Utilizado com: Roadnet, MobileCast
Os conjuntos de habilidades são um grupo de atividades que um funcionário é capaz de
realizar. Por exemplo, um encanador pode ser capaz de executar as seguintes atividades;
instalar uma máquina de lavar, instalar uma máquina de lavar louças e instalar um
triturador de lixo. Em seguida, quando as rotas forem criadas, será possível especificar
que apenas os funcionários com o conjunto de habilidades necessário para atender a um
pedido possa ser atribuído à rota.
Antes de criar os conjuntos de habilidades, é necessário adicionar as atividades. Depois
de criar os conjuntos de habilidades, é possível atribuir um conjunto de habilidades a um
— foncionário.
