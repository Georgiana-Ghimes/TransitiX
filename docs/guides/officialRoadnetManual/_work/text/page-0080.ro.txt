Como trabalhar com campos definidos pelo usuário
Utilizado com: Territory Planner
Os campos definidos pelo usuário permitem armazenar informações adicionais que não
são fornecidas pelo Territory Planner sobre as extensões de cliente. Por exemplo, se você
negocia com redes de lojas e cada loja possuir um número, é possível inserir o número da
1oja como campo definido pelo usuário. As informações armazenadas nos campos
definidos pelo usuário não são usadas pelo Territory Planner, mas são exibidas com as
extensões de cliente e podem ser importadas e exportadas. Os campos definidos pelo
usuário podem ser alfanuméricos ou somente numéricos. Se um campo for designado
como numérico, os totais da coluna serão exibidos na janela Extensões de clientes, na lista
