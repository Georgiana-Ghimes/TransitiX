Como trabalhar com tipos de container
Utilizado com: MobileCast
|O MobileCast oferece a capacidade de usar containers como forma de monitorar os
pedidos associados às rotas. Para ajudar a organizar os containers, é possível configurar
diferentes tipos de container, cada um com um custo a ele associado. Por exemplo, é
possível configurar tipos de container de acordo com o material, como transportadores,
paletes, sacolas, etc.. ou de acordo com o tamanho. Cada tipo de container que você cria
é disponibilizado para todas as suas regiões.
