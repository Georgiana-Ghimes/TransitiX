Como trabalhar com áreas
Utilizado com: Roadnet
As áreas no Roadnet Transportation Suite são simplesmente as regiões — estados,
provincias, etc. — percorridas pelo equipamento. Sua finalidade no Roadnet é permitir
monitorar e relatar as milhas percorridas pelo equipamento em cada área. Consulte Como
trabalhar com as distâncias das áreas para obter mais informações.
Etapa 1: Clique no ícone Manutenção para abrir o respectivo módulo.
Etapa 2: Clique no menu Entrada de dados reais e selecione Áreas. A janela Áreas é
exibida.
Nota: Para ver uma lista atualizada de áreas, clique no ícone Atualizar; a janela será
atualizada com as informações mais recentes do banco de dados.
Etapa 3: Na janela Áreas, clique no ícone Adicionar ou pressione [Insert]. A janeta
Adicionar área é exibida.

Adicionar é exibida com algumas informações já preenchidas; altere as
informações necessárias na nova entrada.

Como trabalhar com zonas
Utilizado com: Roadnet, Territory Planner, FleetLoader
As zonas são utilizadas no Roadnet para agrupar locais de entrega semelhantes em
roteirização dinâmica, de maneira que eles fiquem na mesma rota. ÀAs zonas são
configuradas e, em seguida, atribuídas aos clientes, se necessário. Na roteirização
dinâmica, é possível aplicar um filtro somente às paradas da rota em zonas específicas.
Embora o nome zona indique que os clientes devem ser agrupados geograficamente, as
Zonas são na verdade muito mais flexíveis do que isto. Naturaimente, zonas podem ser
utilizadas geograficamente. Por exemplo, você pode decidir que todos os clientes em um
CEP específico devem ser roteirizados em conjunto. Mas também é possível utilizar
Zonas para roteirizar, por exemplo, todos os locais de uma cadeia de lojas de alto volume
que garante seu próprio equipamento.
Etapa 1: Clique no ícone Manutenção para abrir o respectivo módulo.
Etapa 2: Clique no menu Cadastros e selecione Zonas. A janela Zonas é exibida.
Nota: Para ver uma lista atualizada de áreas, clique no ícone Atualizar; a janela será
atualizada com as informações mais recentes do banco de dados.
