Importação de itens de manutenção
Utilizado com: Roadnet, Territory Planner, FleetLoader, MobileCast
As importações de manutenção permitem importar informações sobre clientes, extensões
de cliente, motoristas, funcionários, equipamentos, tipos de equipamento, SKUs, marcas
de SKU, tipos de embalagem, conjuntos de habilidades, atividades do conjunto de
habilidades e containers de outros arquivos, em vez de digitar essas informações. Você
pode importar itens de manutenção diariamente ou quando ocorrerem mudanças
substanciais em sua operação. Para obter mais informações sobre como importar clientes
u extensões de cliente, consulte Importação de clientes ou Importação de extensões de
cliente. Para obter mais informações sobre como criar layouts, consulte Configuração dos
layouts de arquivo. Para importar motoristas, equipamentos, tipos de equipamento, SKUs,
marcas de SKU, tipos de embalagem, conjuntos de habilidades, atividades do conjunto de
habilidades ou containers, siga as etapas abaixo.
Nota: Para importar itens de manutenção, o tipo correspondente deve ser adicionado. Por
exemplo, para importar funcionários, é preciso adicionar tipos de funcionário.
Consulte Como trabalhar com status e tipos para obter mais informações.
Etapa 1: Clique no ícone Importação para abrir o módulo Importação.
Nota: Se você tiver várias regiões ou cenários, verifique se são exibidos os dados
apropriados na parte inferior da tela. Para alterar a região ou o cenário, basta clicar
na seta e selecionar o item apropriado na lista exibida.
Etapa 2: Clique no menu Importar, selecione Manutenção e o item que deseja importar.
AA janela Importar é exibida. Faça as alterações necessárias em Caminho dos
dados.

Para ver ou alterar o layout do arquivo de importação, clique na seta [Layout do

Para visualizar um relatório que resuma as informações do layout, incluindo o

AA janela Visualizar relatório é exibida com o relatório. Nessa janela, você pode
imprimir ou exportar o relatório.
Se você não recebeu permissão para alterar as opções de importação e exportação
no módulo Administração, não conseguirá alterar as opções selecionadas ao
importar itens de manutenção.
Etapa 3: Ao importar itens de manutenção para um sistema que já tenha funcionários/
motoristas/equipamentos tipos de equipamento/SKUs /marcas de SKU/tipos de
embalagem/containers, você precisa indicar ao Transportation Suíte como lidar
com as duplicatas. Se já houver itens de manutenção dessa região no
Transportation Suíte, Selecione uma opção para situações nas quais os itens
importados tenham a mesma ID dos existentes:
Atualizar — atualiza as informações dos campos com as informações contidas
no arquivo de importação.
Substituir — substitui completamente o item existente pelo novo importado.
Tsso significa que qualquer alteração feita no item original, como a localização
de um equipamento, será perdida.
Erro — ignora os itens do arquivo de importação que tenham uplicatas e exibe
mensagens de erro indicando que os itens não foram importados.
