Importação de extensões de cliente
Utilizado com: Territory Planner
Se você estiver utilizando o Territory Planner para criar rotas de planejamento estratégico,
terá de importar informações de extensão de cliente. As extensões de cliente contém
informações sobre o cliente específico de uma sessão de planejamento. como opções de
entrega (conjunto de padrões de atendimento), quantidade entregue e informações de
roteirização. Ao importar informações de extensões de cliente, é importante ter em mente
algumas regras:
* Seaquantidade de entregas importadas não permitir que cada parada seja dividida
igualmente pelo número de entregas por ciclo, a quantidade será aumentada.
* Um conjunto de padrões de atendimento 0 é chamado de Distribuição de
carregamento manual. Uma extensão de cliente com um conjunto de padrões de
atendimento O não será roteirizada quando Atribuir dias for executado.
* Seumpadrão de atendimento inserido entrar em conflito com o conjunto fornecido,
12 parada será novamente roteirizada conforme o padrão.
* Paraque a extensão de cliente seja importada para a sessão de planejamento, é
preciso importar pelo menos a ID e um outro campo, como conjunto de padrões de
atendimento, quantidade ou território.
Para que as extensões de cliente sejam importadas, os clientes devem ser importados.
Você pode importar os clientes ao mesmo tempo em que 2s extensões ou separadamente.
Consuite Importação de clientes para obter mais informações. Para ver as informações
que podem ser importadas com as extensões de cliente, consulte Campos de layout das
extensões de cliente.
) Importante: Antes de importar extensões de cliente pela primeira vez defína as semanas
ativas padrão e o conjunto padrão de atendimento. As semanas ativas padrão

Semanas ativas padrão são todas as semanas.
