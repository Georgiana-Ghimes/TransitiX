Equipamentos e o MobileCast
Se você estiver utilizando o MobileCast para monitorar as rotas durante o dia, é necessário
preencher informações adicionais sobre o equipamento, como disposítivos sem fio,
telefones WAP ou computadores de bordo associados ao equipamento.
Etapa 1: Se você estiver utilizando o MobileCast, clique na guia Expedir na janela
Equipamento.
Etapa 2: Se estiver utilizando um telefone ativado para WAP, insira a ID da unidade
GPS. O MobileCast utiliza esta ID para associar o item de equipamento a uma
rota específica.
Etapa 3: Se um disposítivo sem fio for atribuído ao equipamento, selecione o provedor e
aD.
. Nota: Se você estiver utilizando versões mais novas do aplicativo móvel, nas quais o
motorista faz logon no dispositivo, não é necessário atribuir um disposítivo sem fio
20 equipamento.
Etapa 4: Se o equipamento possui um computador de bordo, selecione 2 caixa
Computador de bordo.
Etapa 5: Insira o focal de início das rotas do equipamento, como o depósito. Clique na
seta próxima 20 campo Tipo para selecionar um tipo e insira a ID ou pesquise o
cliente. Para adiciona rum novo cliente, clique no botão [Novo]. Esse campo
deve ser preenchido.
Etapa 6: Para reposicionar o equipamento manualmente em um local de entrega, insira a
data e hora de entrega nos campos Recebido.
