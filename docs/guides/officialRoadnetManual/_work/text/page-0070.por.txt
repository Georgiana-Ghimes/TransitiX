Como trabalhar com tipos de cliente
Utilizado com: Roadnet, Territory Planner, FleetLoader, MobileCast
Tipos de cliente permite a especificação dos tipos de clientes existentes. Normamente, o
tipo de cliente é simplesmente uma ID e uma descrição, mas você pode atribuir os tipos
aos seus clientes para distinguir os depósitos de clientes e de fornecedores, separar
departamentos em um supermercado — inúmeras utilizações. Se você estiver utilizando
tipos de clientes para diferenciar os diversos departamentos de uma única loja, como um
supermercado, é possível fazer com que o Roadnet Transportation Suite sincronize
avtomaticamente os campos selecionados para cada tipo ao adicionar ou editar um cliente;
consulte a página Clientes de Definição das opções para obter mais informações. Se
estiver utilizando a parte de contabilidade do MobileCast, é possível associar um tipo de
monitoramento a um tipo de cliente, para diferenciar o custo de entrega a diferentes tipos
de clientes.
O Roadnet Transportation Suíte é fornecido com dois tipos de clientes padrão: depósitos
(DPT) e fábricas (SIT), mas você pode adicionar quantos forem necessários.

Como trabalhar com clientes
Utilizado com: Roadnet, Territory Planner, FleetLoader, MobileCast
Os clientes são qualquer ponto para onde um veículo é enviado, como endereços de
clientes, depósitos, fomecedores de produtos, etc. O Roadnet Transportation Suíte coloca
os clientes em um mapa de acordo com seus geocódigos (latitude e longitude). É possível
associar diversas características a um cliente, incluindo o endereço, telefone e número de
fax; segmento de cliente, janela de atendimento e tipo de tempo de atendimento, e
alterações de janela e de tempo de atendimento. Os clientes podem ser importados por
meio do módulo Importação ou adicionados individualmente. Consulte Importação de
clientes para obter mais informações sobre como usar o módulo Importação para importar
clientes. Os tipos de clientes devem ser adicionados para poder adicionar os clientes
