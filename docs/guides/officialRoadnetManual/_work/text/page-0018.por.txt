Clonagem de itens
É possível clonar itens de manutenção existentes. Ao clonar um item, a maior parte das
informações necessárias é preenchida quando a janela Adicionar é exibida, reduzindo a
quantidade de texto que é necessário digitar. Você pode alterar qualquer das informações
existentes, conforme necessário.
Para adicionar uma entrada semelhante a outra existente, clique com o botão direito do
mouse na entrada existente e selecione Clonar no menu exibido. À janela Adicionar é
exibida com algumas informações já preenchidas; altere as informações necessárias na
nova entrada.
Edição de itens
Após a adição de itens no módulo Manutenção, é possível alterá-los conforme necessário.
