Definição dos aliases padrão
Utilizado com: Roadnet, Territory Planner, FleetLoader, MobileCast
A página Alias do menu Opções permite configurar os aliases de tamanho e categoria e
s campos definidos pelo usuário para os clientes. Este é o único local no qual é possível
estabelecer ou alterar esses paórões no Roadnet Transportation Suite.
s aliases de tamanho escolhidos aqui aparecerão em todo o Roadnet
Transportation Suíte sempre que tamanhos forem exibidos.
Etapa 1: Insira os nomes de cada uma das unidades (Tamanho 1, Tamanho ? e Tamanho
3) e de cada categoria (Categoria 1, Categoria 2 e Categoria 3). Estes nomes
aparecerão em todo o Transportation Suíte como cabeçalhos de coluna e em
relatórios, sempre que esses dados aparecerem.
Nota: As categorias são utilizadas apenas no Roadnet.
Etapa 2: Se necessário, atribua nomes ou cabeçalhos a um ou mais campos definidos
pelo usuário (Definido pelo usuário 1, 2 e 3). Esses são campos definidos pelo
usuário que podem ser utilizados para inserir informações adicionais de
cliente, parada, pedido ou item do pedido. Os campos de cliente definidos pelo
usuário são utilizados por todo o Transportation Suíte. Os campos de pedido e
item do pedido definidos pelo usuário são utilizados com o Roaánet e o
MobileCast; os campos de rota e parada definidos pelo usuário são utilizados
somente no MobileCast.
