Como trabalhar com privilégios

Privilégios são grupos de direitos que os usuários têm no Transportation Suíte. Você pode
criar vários privilégios, sendo que cada um deles terá acesso a partes diferentes do
programa. Por exemplo, você pode criar um privilégio chamado Operador com direitos
de acesso ao Editor de roteirização, mas não ao Editor de carregamentos, e outro
privilégio chamado Carregador com direitos de acesso ao Editor de carregamentos, mas
não ao Editor de roteirização. Após a criação dos privilégios, você pode atribuí-los aos
usuários ou grupos de cada região.
Etapa 1: Clique no icone Administração para abrir o módulo Administração.
Etapa 2: Clique no menu Cadastros e selecione Privilégios. A janela Privilégios é
exibida contendo os privilégios existentes.
Etapa 3: Na janela Privilégios, clique no ícone Adicionar ou pressione [Insert]. A janela
Add Privilege (Adicionar privilégio) é exibida.
