Estabelecimento de regras de empilhamento
Utilizado com: FleetLoader
As regras de empilhamento proibem que um tipo de embalagem específico seja
empilhado sobre outro tipo de embalagem, quando o equipamento é carregado com o
FleetLoader. Por exemplo, pode-se estabelecer uma regra proibindo o empilhamento de
latas sobre garrafas. Diferente das regras de produto, as regras de empilhamento não são
inversíveis; uma regra de empilhamento evitando que latas sejam empilhadas sobre
garrafas não impede que garrafas sejam empilhadas sobre latas.
. Nota: Não utilize regras de empilhamento para evitar o carregamento de SKUs juntas no
mesmo compartimento/na mesma camada; use as regras de produto para impedir
esta mistura.

(Como trabalhar com métodos de camadas de paletes
Como trabalhar com métodos de camadas de paletes
Utilizado com: FleetLoader
OOs métodos de camadas de paletes permitem criar diversas maneiras nas quais os tipos de
embalagem podem ser montados em um palete. Por exemplo, você pode montar paletes
de mancira diferente para fins-de-semana de feriado, para colocar mais produtos em cada
palete. Para permitir estas situações, crie um método separado para feriados, que será
usado somente nessas circunstâncias especiais. Quando os veículos são carregados com o
Editor de carregamentos, um método de camadas de palete deve ser especificado; caso
não seja especificado, o método de camadas padrão será utilizado.
Após adicionar os métodos de camadas, é possível definir a quantidade do tipo da
embalagem que pode ser ajustada em uma camada e o número de camadas que podem ser
ajustadas em um palete. Consuíte Como trabalhar com tipos de embalagem para obter
mais informações.
O Transportation Suite é fornecido com um método de camadas de palete padrão,
denominado Padrão (STD). Este método não pode ser excluído, mas pode ser alterado.
WVocê pode adicionar quantos métodos de camadas de palete forem necessários.
