Como trabalhar com sessões de planejamento
Utilizado com: Territory Planner
As sessões de planejamento são uma maneira de agrupar as informações necessárias para
resolver problemas de roteirização no Territory Planner. Elas também permitem alterar
parâmetros e tentar diferentes variáveis “possíveis” sem perder rotas existentes. Quando
Você entra no Editor de planejamento, deve selecionar uma sessão específica com a qual
trabalhar. As sessões de planejamento podem ser adicionadas importando extensões de
clientes ou escolhendo Transferência de sessão quando estiver no Editor de planejamento.

Etapa 6: Selecione o tipo de Cálculo de tempo/distância a ser usado para 2 sessão de

XY é um método de roteirização que utiliza uma linha direta para medir a
distância entre dois pontos. Ele conta com modelos de distância e de tempo de
percurso para curvas e voltas no percurso, bem como velocidades variáveis. Se
comparado 20 RouteNet, o método XY é mais rápido de usar, porém menos
preciso.
Usar barreiras pode ser selecionado somente quando o método XY estiver
sendo usado. Esta opção explica as barreiras reais entre dois pontos, como um
corpo de água, uma montanha, etc. As barreiras devem ser criadas no modo
Barreira no mapa.
RouteNet é um método de cálculo que utiliza mapas para replicar as condições
Teais das vias, levando tudo em consideração, desde placas de Pare e semáforos
até os limites de velocidade e alterações de percurso. Comparado ao método
XY, o RouteNet demora um pouco mais para ser processado, mas é mais
preciso.
. Nota: Utilizar o RouteNet pode causar uma demora significativa ao entrar no Editor de
roteirização ou de planejamento, enquanto os tempos e distâncias são calculados.
A duração desse atraso é baseada em diversos fatores, incluindo:
* o número de clientes com pedidos
* o número de depósitos
* o número de ruas na área geográfica
* o poder de processamento do computador
Se você deseja evitar esta demora, utilize o SuperMatrix.
SuperMatrix é um outro método de cálculo que utiliza a rede de vias para replicar
s condições reais das vias, levando tudo em consideração, desde placas de Pare e
semáforos até os limites de velocidade e alterações de percurso. É possível
programar o SuperMatrix para que seja executado à noite, de forma que não seja
necessário aguardar o cálculo dos tempos e distâncias de percurso 2o entrar nos
editores. Se estiver utilizando o SuperMatrix, é necessário especificar como você
deseja que o Editor de planejamento trate os clientes que foram adicionados desde
2 última execução do SuperMatrix. Na área Atualização em tempo real, selecione
se deseja utilizar XY ou RouteNet para calcular as distâncias até esses clientes,
