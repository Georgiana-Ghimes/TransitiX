Como trabalhar com destinatários de notificação
Utilizado com: MobileCast
Destinatários de notificação são programas extemos que coletam informações sobre
eventos que ocorrem no Transportation Suite. À medida que os eventos desse destinatário
ocorrem, o Transportation Suíte os coleta e, quando o programa pesquisa o Transportation
Suite, as informações são transferidas para o programa. Por exemplo, talvez você tenha
um software chamado Atualização que precise das informações de chegada e partida das
paradas dos motoristas contidas nos dispositivos sem fio deles para atualizar o sistema
interno da empresa; para que essas informações sejam transferidas, você configura um
destinatário de notificação para o programa Atualização e seleciona Chegada na parada -
Dispositivo e Partida da parada - Disposítivo na lista Subscription (Assinatura). Os
destinatários de notificação devem ser utilizados com o Integration Platform Service.

Destinatários de notificação é exibida contendo os destinatários de notificação
existentes.

[Insert]. A janela Add Notification Recipient (Adicionar destinatário de
