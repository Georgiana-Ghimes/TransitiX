Criação de conjuntos de layouts de importação
Informações de cliente, extensão de cliente, pedido, manutenção e computador de bordo
podem ser importadas de um host ou de outro computador para o Roaánet Transportation
Suite. Para que o programa aceite essas informações e as coloque onde possam ser
acessadas e utilizadas, você deve informá-lo onde encontrá-las nos arquivos de
importação. Os layouts de importação são utilizados para comunicar essas informações
ao Roadnet Transportation Suíte. É possível agrupar layouts de importação para importar
conjuntos de layouts que são personalizados para suas diferentes necessidades de
importação. Os conjuntos de layouts de importação permitem agrupar layouts de
importação. E, como é possível ter vários conjuntos, você pode criar conjuntos diferentes
para várias situações de importação.
Para que o layout de arquivo de importação possa ser criado, é preciso ter pelo menos um
conjunto de layouts de importação criado.
